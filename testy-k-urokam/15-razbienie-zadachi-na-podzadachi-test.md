### Ответы к Части В (макс. 351 балл)

**8\.**
*Ожидаемое решение:*

Подзадачи: 1) сумма цифр числа — функция sum_digits(n) с циклом while и return s; 2) перебор двузначных чисел — for x in range(10, 100); 3) проверка и вывод — if sum_digits(x) == 9: print(x). Ответ программы: 18, 27, 36, 45, 54, 63, 72, 81, 90 — девять чисел. Проверка: у 90 сумма цифр 9 + 0 = 9, у 18 — 1 + 8 = 9.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**9\.**
*Ожидаемое решение:*

Команда return стоит внутри цикла (с отступом), поэтому функция завершается на первом шаге и возвращает только последнюю цифру: sum_digits(345) вернёт 5 вместо 12. Строка n = n // 10 записана после return и без отступа, поэтому не выполняется никогда. Исправление: n = n // 10 перенести внутрь цикла сразу после s += n % 10, а return s вынести из цикла — записать без отступа после его окончания.

*Оценивание: 345 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**10\.**
*Ожидаемое решение:*

Функция: cnt = 0, затем for d in range(1, n + 1) и внутри if n % d == 0: cnt += 1, после цикла return cnt. Главная часть: for x in range(1, 61): if count_divisors(x) == 4: print(x). Проверка: делители 6 — это 1, 2, 3, 6, всего 4; делители 8 — 1, 2, 4, 8, тоже 4, поэтому оба числа попадут в вывод. Среди чисел до 60 четыре делителя имеют, например, 6, 8, 10, 14, 15, 21, 22, 26, 27, 33, 34, 35, 38, 39, 46, 51, 55, 57, 58.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*
