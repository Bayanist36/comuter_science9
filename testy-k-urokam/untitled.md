# Проверочный тест по теме «Глобальная сеть Интернет. IP-адреса узлов. Большие данные»

**Максимальный балл:** 25 баллов

---

## Часть А. Задания с выбором одного правильного ответа (по 1 баллу)

*Выберите один верный вариант ответа.*

---

**А1.** Что такое Интернет?

1) Один мощный компьютер, к которому подключены все пользователи мира
2) Глобальная система объединённых компьютерных сетей, работающих по протоколам TCP/IP
3) Программа для просмотра веб-страниц
4) Кабель, проложенный по дну океана и соединяющий континенты

---

**А2.** Какое устройство перенаправляет пакеты данных между различными сегментами сети, выбирая оптимальный маршрут?

1) Сервер
2) Коммутатор
3) Маршрутизатор (роутер)
4) Жёсткий диск

1) Чтобы увеличить объём передаваемой информации

3) Чтобы обеспечить надёжность доставки и возможность передачи данных разными маршрутами
4) Чтобы уменьшить скорость передачи и не перегружать канал

## Часть В. Задания повышенного уровня (по 2 балла)

---

**В1.** Установите соответствие между элементом сети и его функцией.

| Элемент сети | Функция |
|---|---|
| А) Сервер | 1) Запрашивает данные у других устройств |

| В) Маршрутизатор | 3) Хранит информацию и предоставляет услуги другим устройствам |

**В2.** Выберите **все** верные утверждения (может быть несколько правильных ответов):

## Часть С. Задания с развёрнутым ответом

---

### Часть В (по 2 балла за каждый полностью верный ответ)

**В1.** Ответ: **3124**

| Элемент | Функция |
|---|---|
| А) Сервер | 3 — Хранит информацию и предоставляет услуги |
| Б) Клиент | 1 — Запрашивает данные |
| В) Маршрутизатор | 2 — Перенаправляет пакеты |
| Г) Провайдер | 4 — Предоставляет доступ в Интернет |

**В2.** Ответ: **2, 3, 5**

Пояснение:
- (1) — неверно: локальный адрес НЕ виден в глобальной сети;
- (2) — верно;
- (3) — верно: 192.168.x.x — частный диапазон;
- (4) — неверно: IPv6 занимает 128 бит;
- (5) — верно;
- (6) — неверно: для обработки больших данных требуются распределённые системы.

**В3.** Ответ: **00001010.00000000.00000001.00000101**

Перевод:
- 10₁₀ = 00001010₂
- 0₁₀ = 00000000₂
- 1₁₀ = 00000001₂
- 5₁₀ = 00000101₂

*(2 балла — полностью верно; 1 балл — допущена одна ошибка в переводе; 0 баллов — более одной ошибки.)*

### Часть С

**С1.** Критерии оценивания (максимум 3 балла):

| Баллы | Критерий |
|-------|----------|
| 1 | Дано объяснение отличия больших данных от обычного набора файлов (объём, скорость поступления, разнообразие форматов, невозможность обработки традиционными средствами) |
| 1 | Приведены два конкретных примера из повседневной жизни |
| 1 | Для примеров указаны проявляющиеся характеристики «три V» |

*Пример ожидаемого ответа:*
«Большие данные отличаются от обычных файлов тем, что имеют огромный объём (терабайты и петабайты), поступают непрерывно в реальном времени и имеют разнородную структуру (текст, видео, числа, геолокация). Обработать их на одном компьютере невозможно. Пример 1: навигатор строит маршрут с учётом пробок — анализирует скорость тысяч автомобилей (Volume, Velocity). Пример 2: музыкальный сервис рекомендует треки на основе миллионов прослушиваний разных пользователей (Volume, Variety).»
