## Часть А. Задания с выбором одного правильного ответа (по 1 баллу)

*Выберите один верный вариант ответа.*

---

**А1.** Что такое облачные технологии?

1. Технологии для создания трёхмерной графики и виртуальной реальности
2. Модель предоставления вычислительных ресурсов и программного обеспечения через сеть Интернет
3. Способ беспроводной передачи данных между мобильными устройствами
4. Комплекс мер по защите компьютерных сетей от вредоносного кода

**А2.** Какая модель облачных сервисов предоставляет пользователю готовые приложения (например, онлайн-офис) через браузер без необходимости их установки?

1. IaaS (Инфраструктура как сервис)
2. PaaS (Платформа как сервис)
3. SaaS (Программное обеспечение как сервис)
4. DaaS (Данные как сервис)

**А3.** Какое главное преимущество онлайн-офиса перед локальным текстовым процессором?

1. Более широкий набор функций для сложной профессиональной вёрстки
2. Возможность полноценной работы без подключения к Интернету
3. Возможность одновременного совместного редактирования документа несколькими пользователями в реальном времени
4. Полная независимость от серверов компании-разработчика

**А4.** Что означает функция «автосохранение» в онлайн-офисе?

1. Документ сохраняется на жёсткий диск компьютера каждые 5 минут
2. Документ автоматически сохраняется в облаке при каждом внесении изменений
3. Документ распечатывается автоматически после завершения работы
4. Документ отправляется по электронной почте учителю при закрытии вкладки

**А5.** Для чего предназначена «История версий» в онлайн-документе?

1. Для безвозвратного удаления старых версий документа с целью экономии места в облаке
2. Для просмотра того, кто и когда вносил изменения, и восстановления предыдущих состояний документа
3. Для автоматического исправления грамматических и пунктуационных ошибок
4. Для перевода документа на другие языки с сохранением форматирования

**А6.** Какой уровень прав доступа следует предоставить учителю, чтобы он мог проверить вашу работу и оставить замечания, но не мог случайно удалить или изменить ваш текст?

1. Владелец
2. Редактирование
3. Комментирование (или Только просмотр)
4. Полный доступ

**А7.** Что такое «комментарий» в онлайн-документе?

1. Скрытый текст, который виден только владельцу документа
2. Заметка, привязанная к фрагменту текста, не изменяющая сам документ
3. Автоматически сгенерированное оглавление документа
4. Сноска со ссылкой на внешний сайт

**А8.** Какая функция облачного хранилища обеспечивает актуальность файлов на смартфоне, планшете и компьютере одновременно?

1. Архивация
2. Версионность
3. Синхронизация
4. Индексация

**А9.** Что из перечисленного НЕ является стандартным компонентом типичного онлайн-офиса?

1. Текстовый редактор
2. Электронные таблицы
3. Редактор презентаций
4. Антивирусный сканер

**А10.** Какое действие является грубым нарушением безопасности при работе с облачными сервисами?

1. Включение двухфакторной аутентификации для входа в аккаунт
2. Использование одного и того же простого пароля для всех облачных хранилищ и почты
3. Регулярная проверка списка устройств и сессий, имеющих доступ к аккаунту
4. Предоставление доступа к документу по ссылке с правом «только просмотр»

**А11.** В каком формате чаще всего можно экспортировать (скачать) документ, созданный в онлайн-офисе, для дальнейшей работы в локальном текстовом процессоре?

1. .mp3
2. .exe
3. .docx
4. .zip

**В2.** Выберите **ВСЕ** верные утверждения о совместной работе в онлайн-офисе:

1. При одновременном редактировании каждый пользователь видит курсоры других участников.
2. Для совместной работы всем участникам необходимо установить одну и ту же локальную программу на свои компьютеры.
3. Если один участник случайно удалит текст, восстановить его с помощью истории версий невозможно.
4. Комментарии позволяют обсуждать фрагменты текста, не изменяя сам документ.
5. Изменения, внесённые одним участником, мгновенно отображаются у других при наличии подключения к Интернету.

Запишите номера всех верных утверждений.

**В3.** Расположите в правильном порядке действия ученика, который хочет поделиться документом с одноклассником так, чтобы тот мог только читать текст, но не редактировать его.

А) Скопировать сгенерированную ссылку и отправить её однокласснику.
Б) Открыть меню настройки совместного доступа (кнопка «Поделиться» или «Настройки доступа»).
В) Выбрать уровень прав «Только просмотр» (или «Чтение»).
Г) Открыть документ в онлайн-офисе.

Запишите ответ в виде последовательности букв.

**В4.** Выберите ситуации, в которых использование онлайн-офиса является **БОЛЕЕ предпочтительным**, чем локального текстового процессора:

1. Создание сложного документа с использованием специфических макросов в условиях полного отсутствия Интернета.
2. Подготовка группового проекта, где трое учеников работают из дома в одно и то же время.

4. Совместное ведение протокола собрания с возможностью оставления комментариев от разных участников.

Запишите номера всех подходящих ситуаций.

### Часть С (максимум 6 баллов)

**С1.** Критерии оценивания (3 балла):

- **1 балл:** Дан верный ответ (текст не потерян) с обоснованием (в онлайн-офисах работает автосохранение и ведётся история версий, где фиксируются все изменения).
- **1 балл:** Описан алгоритм восстановления (Открыть документ -> Меню «Файл» / «История версий» -> Найти версию до момента удаления -> Восстановить её или скопировать нужный фрагмент в текущую версию).
- **1 балл:** Указано нарушенное правило (Нельзя удалять чужой текст без согласования; при сомнениях нужно использовать комментарии, а не прямое удаление; следует работать в разных частях документа).

*Пример ответа:* «1) Текст не потерян безвозвратно, так как онлайн-офис автоматически сохраняет все изменения и ведёт историю версий. 2) Алгоритм: нужно открыть меню "Файл" -> "История версий", найти сохранение, сделанное до нажатия клавиши Delete, открыть его и скопировать удалённый фрагмент обратно в актуальную версию документа. 3) Было нарушено правило этики совместной работы: нельзя удалять или существенно изменять текст, написанный другим участником, без его согласия. Для замечаний следовало использовать функцию "Комментарий".»

**С2.** Критерии оценивания (3 балла):

- **1 балл:** Указана ошибка (Ученица открыла доступ ко всей папке, а не к конкретному документу, и, вероятно, выдала права на "Редактирование", а не "Просмотр", разместив ссылку в публичном чате).
- **1 балл:** Указаны проигнорированные меры ИБ (Принцип минимальных привилегий, проверка настроек доступа перед отправкой ссылки, неразглашение ссылок на личные данные в открытых каналах).
- **1 балл:** Сформулирован правильный алгоритм (Открыть конкретный документ -> Нажать "Поделиться" -> Ввести email учителя/одноклассника ИЛИ сгенерировать ссылку с правом "Только просмотр" -> Отправить ссылку лично получателю).

*Пример ответа:* «1) Ошибка: она дала доступ ко всей папке (вместо одного документа) и, скорее всего, с правами на редактирование, опубликовав ссылку в общем чате, где её мог увидеть и использовать кто угодно. 2) Она проигнорировала принцип минимальных привилегий (дать ровно тот доступ, который нужен) и правило неразглашения ссылок на личные файлы в публичных пространствах. 3) Правильный алгоритм: открыть сам документ с эссе, нажать "Поделиться", выбрать уровень доступа "Только просмотр" (или "Комментирование"), ввести электронный адрес учителя и отправить доступ напрямую ему, не публикуя ссылку в общем чате.»
