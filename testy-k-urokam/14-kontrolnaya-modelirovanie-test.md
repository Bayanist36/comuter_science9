# 🔑 КЛЮЧИ И КРИТЕРИИ ОЦЕНИВАНИЯ (для учителя)

### Ответы к Части А (макс. 5 баллов)

1. **б** — Граф состоит из вершин-объектов и рёбер-связей между ними.
2. **в** — В любом дереве из n вершин ровно n − 1 ребро, поэтому 7 − 1 = 6.
3. **а** — В неориентированном графе связь A–B и B–A одна и та же, поэтому клетки вне диагонали повторяются.
4. **б** — ИЛИ требует выполнения хотя бы одного условия, поэтому подходящих строк становится больше.
5. **в** — Эксперимент — это серия расчётов с разными значениями параметров, результаты которой сводят в таблицу и на график.

### Ответы к Части Б (макс. 4 балла)

*Оценивание: 2 балла — ответ полный и верный; 1 балл — ответ неполный; 0 баллов — ответ неверный.*

### Ответы к Части В (макс. 9 баллов)

**8\.**
*Ожидаемое решение:*

Все пути и их длины: A-B-C-D-E = 4 + 2 + 3 + 2 = 11; A-B-D-E = 4 + 6 + 2 = 12; A-C-D-E = 7 + 3 + 2 = 12; A-B-C-E = 4 + 2 + 8 = 14; A-C-E = 7 + 8 = 15. Кратчайший — A-B-C-D-E длиной 11. При весе C → E, равном 3, путь A-B-C-E даёт 4 + 2 + 3 = 9, и он становится кратчайшим: 9 < 11. Остальные пути не изменились, поэтому новый ответ — A-B-C-E, длина 9.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**9\.**
*Ожидаемое решение:*

Таблица: строки — принтеры, столбцы — скорость печати, ресурс картриджа, цена картриджа, цена страницы. Цена страницы: 2400 / 3000 = 0,8 рубля у первого, 1500 / 2000 = 0,75 рубля у второго, 4500 / 5000 = 0,9 рубля у третьего. Дешевле всего печать у второго принтера. Запрос «Ресурс > 2500 И Цена < 2500» отбирает только первый принтер: у него ресурс 3000 и цена 2400; второй не проходит по ресурсу, третий — по цене.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**10\.**
*Ожидаемое решение:*

Расхождение обнаружено на шестом этапе — анализе результатов и уточнении модели. Причина в допущении: модель не учитывает сопротивление воздуха, поэтому расчёт даёт высоту больше реальной, разница 20 − 17 = 3 м, то есть 15% от расчётного значения. Уточнение: добавить в модель силу сопротивления воздуха или ограничить область применимости и указывать, что формула верна лишь для малых скоростей. Программа считает по формуле верно, тесты на данных с известным ответом проходят, поэтому дело не в коде, а в самой модели: проверку кода и проверку адекватности путать нельзя.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*
