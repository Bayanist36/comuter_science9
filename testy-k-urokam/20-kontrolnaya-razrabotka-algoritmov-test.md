### Ответы к Части В (макс. 9 баллов)

**8\.**
*Ожидаемое решение:*

cnt = 0; for x in a: if x > 10: cnt += 1; print(cnt). Подходят 15, 22 и 11 — три элемента. Ответ: 3.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**9\.**
*Ожидаемое решение:*

Проход 1: (2,4) без обмена, (4,1) → [2,1,4,3], (4,3) → [2,1,3,4]; два обмена. Проход 2: (2,1) → [1,2,3,4], остальные пары верны; третий обмен. Проход 3: обменов нет, флаг остался False, цикл прерывается. Ответ: [2, 1, 3, 4], затем [1, 2, 3, 4]; остановка на третьем проходе, всего 6 сравнений и 3 обмена.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**10\.**
*Ожидаемое решение:*

Сторож 0 в обработку не входит: элементы 6, −2, 10, их количество 3, сумма 6 − 2 + 10 = 14, среднее 14 / 3 ≈ 4,67. Если проверку сторожа поставить после накопления, количество станет 4, а среднее 3,5.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*
