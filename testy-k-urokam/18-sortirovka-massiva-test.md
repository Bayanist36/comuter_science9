# 🔑 КЛЮЧИ И КРИТЕРИИ ОЦЕНИВАНИЯ (для учителя)

### Ответы к Части А (макс. 5 баллов)

1. **в** — Метод sort изменяет сам список и не возвращает значения, поэтому результат равен None.
2. **в** — Сравнений ровно n(n−1)/2 = 5·4/2 = 10, и это число не зависит от исходного порядка.
3. **б** — Проход сравнивает пары (4,1), (4,3), (4,2): после трёх обменов наибольший элемент 4 уходит в конец, остальные сдвигаются влево.
4. **в** — Аргумент key=len задаёт ключ сравнения — длину слова, направление по умолчанию возрастающее.
5. **в** — Обмен выполняется не более одного раза за проход, а проходов n − 1 = 9.

### Ответы к Части Б (макс. 4 балла)

**6\.** Проход 1: (9,4) → [4,9,7,2]; (9,7) → [4,7,9,2]; (9,2) → [4,7,2,9]. Проход 2: сравниваются только пары (4,7) и (7,2): (4,7) без обмена, (7,2) → [4,2,7,9]. Ответ: [4, 2, 7, 9].
*Оценивание: 2 балла — ответ полный и верный; 1 балл — ответ неполный; 0 баллов — ответ неверный.*

**7\.** ['я', 'мама', 'папа', 'брат']. Длины слов: 1, 4, 4, 4; три слова с равным ключом сохранили исходный порядок благодаря устойчивости сортировки.
*Оценивание: 2 балла — ответ полный и верный; 1 балл — ответ неполный; 0 баллов — ответ неверный.*

### Ответы к Части В (макс. 9 баллов)

**8\.**
*Ожидаемое решение:*

Программа: a = [4, 1, 7, 2, 9, 3]; for i in range(len(a) - 1): m = i; for j in range(i + 1, len(a)): if a[j] > a[m]: m = j; a[i], a[m] = a[m], a[i]; print(a). Результат [9, 7, 4, 3, 2, 1]. Сравнений 5 + 4 + 3 + 2 + 1 = 15, то есть 6·5/2. Если массив уже упорядочен по убыванию, число сравнений не изменится: внутренний цикл всегда просматривает весь хвост, меняется только число обменов (ноль).

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**9\.**
*Ожидаемое решение:*

Проход 1: (2,3) без обмена, (3,1) → [2,1,3,4], (3,4) без обмена. Проход 2: (2,1) → [1,2,3,4], остальные пары без обменов. Проход 3: обменов нет, флаг swapped остался False, внешний цикл прерывается. Ответ: после первого прохода [2, 1, 3, 4], после второго [1, 2, 3, 4]; остановка на третьем (проверочном) проходе, всего 2 обмена.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**10\.**
*Ожидаемое решение:*

Выбором: 1000·999/2 = 499 500 сравнений. Встроенная: 1000·log₂1000 ≈ 1000·9,97 ≈ 9970 сравнений. Отношение 499500 : 9970 ≈ 50, то есть примерно в 50 раз меньше. Причина в порядке роста: n²/2 растёт как квадрат длины, а n·log₂n — почти линейно, поэтому с увеличением массива разрыв только увеличивается.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*
