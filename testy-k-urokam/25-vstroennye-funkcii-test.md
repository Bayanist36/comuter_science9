# 🔑 КЛЮЧИ И КРИТЕРИИ ОЦЕНИВАНИЯ (для учителя)

### Ответы к Части А (макс. 5 баллов)

1. **б** — СЧЁТЗ учитывает любые заполненные ячейки, поэтому его результат больше или равен результату СЧЁТ.
2. **в** — Числа 10, 20 и 30 дают сумму 60, количество чисел 3, среднее 60 / 3 = 20.
3. **в** — МАКС игнорирует пустые ячейки и при отсутствии чисел возвращает 0, поэтому итог нужно проверять по СЧЁТ.
4. **б** — Диапазон задаётся двоеточием между адресами первой и последней ячейки.
5. **в** — СРЗНАЧ делит сумму на количество чисел; при нулевом количестве деление невозможно.

### Ответы к Части Б (макс. 4 балла)

**6\.** Сумма 108, среднее 108 / 6 = 18, минимум 4, максимум 42.
*Оценивание: 2 балла — ответ полный и верный; 1 балл — ответ неполный; 0 баллов — ответ неверный.*

**7\.** 16,67. Числа 12, 8 и 30 дают сумму 50, количество чисел 3, среднее 50 / 3 ≈ 16,6667, то есть 16,67.
*Оценивание: 2 балла — ответ полный и верный; 1 балл — ответ неполный; 0 баллов — ответ неверный.*

### Ответы к Части В (макс. 9 баллов)

**8\.**
*Ожидаемое решение:*

Числа: 5, 8, 12, 0, 7, 15, 3 — семь значений, СЧЁТ = 7; ноль тоже число и входит в подсчёт. Сумма 5 + 8 + 12 + 0 + 7 + 15 + 3 = 50. Непустые ячейки: эти семь чисел плюс «нет» и «—», итого 9, СЧЁТЗ = 9; пустая ячейка не считается. СРЗНАЧ = 50 / 7 ≈ 7,14. Если бы среднее считали как 50 / 9, получилось бы 5,56 — это типичная ошибка при делении на СЧЁТЗ.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**9\.**
*Ожидаемое решение:*

СЧЁТЗ считает все непустые ячейки, включая текст, а среднее арифметическое определяется только по числам. Если в диапазоне есть хотя бы одна текстовая ячейка, знаменатель окажется больше числа слагаемых, и результат будет занижен. Формула совпадёт с СРЗНАЧ только тогда, когда СЧЁТ равно СЧЁТЗ, то есть все заполненные ячейки содержат числа. Проверка: сравнить =СЧЁТ и =СЧЁТЗ и убедиться, что они равны.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**10\.**
*Ожидаемое решение:*

1) Записать =СУММ(B2:B13) — прочерки-текст пропустятся автоматически. 2) Записать =СРЗНАЧ(B2:B13) — деление пойдёт на 10 месяцев с данными. 3) Записать =МАКС(B2:B13) и =МИН(B2:B13) для лучшего и худшего месяца. 4) Сравнить =СЧЁТ(B2:B13) с =СЧЁТЗ(B2:B13): разница 2 подтвердит, что прочерки распознаны как текст, а не как нули. 5) Проверить среднее по смыслу: оно должно лежать между минимумом и максимумом. В выводах указать, что среднее посчитано по 10 месяцам, иначе читатель отчёта решит, что учтены все 12.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*
