# 🔑 КЛЮЧИ И КРИТЕРИИ ОЦЕНИВАНИЯ (для учителя)

### Ответы к Части А (макс. 5 баллов)

1. **б** — Ноль не меняет результат сложения, поэтому сумма собирается корректно с первого шага.
2. **в** — Только первый элемент гарантирует, что найденное значение действительно есть в массиве, в том числе если все числа отрицательные.
3. **а** — Счётчик фиксирует количество элементов, для которых условие выполнилось.
4. **в** — В худшем случае нужный элемент стоит последним или отсутствует, поэтому проверяются все n элементов.
5. **б** — В среднем участвуют лишь подходящие элементы, поэтому делитель — их количество.

### Ответы к Части Б (макс. 4 балла)

**6\.** Сумма: 5 − 2 + 8 − 9 + 4 = 6. Максимум 8. Отрицательных элементов два: −2 и −9.
*Оценивание: 2 балла — ответ полный и верный; 1 балл — ответ неполный; 0 баллов — ответ неверный.*

**7\.** В массиве нет отрицательных чисел, поэтому условие x < 0 не выполнится ни разу, флаг останется равным False, и программа выведет False.
*Оценивание: 2 балла — ответ полный и верный; 1 балл — ответ неполный; 0 баллов — ответ неверный.*

### Ответы к Части В (макс. 9 баллов)

**8\.**
*Ожидаемое решение:*

Программа: s = 0, m = a[0], imax = 0, затем цикл for i in range(len(a)), в котором s += a[i], а при a[i] > m выполняется m = a[i] и imax = i. После цикла печатаются s, round(s / len(a), 2), m, imax. Сумма 4 + 5 + 3 + 5 + 2 + 4 + 5 = 28, среднее 28 / 7 = 4.0, максимум 5, первый элемент с этим значением имеет индекс 1.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**9\.**
*Ожидаемое решение:*

Ошибка в делителе: сумму отличных оценок делят на длину массива, а нужно делить на количество отличных оценок, то есть на cnt. Правильно: print(s / cnt). Сумма отличных оценок 5 + 5 = 10, их две, среднее равно 10 / 2 = 5.0, а не 10 / 5 = 2.0.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**10\.**
*Ожидаемое решение:*

Три отдельных цикла выполнят 3n шагов, а один цикл — n шагов, потому что все три накопителя можно обновлять в одном проходе. Решение с одним циклом лучше по времени работы и короче по записи, но требует большей внимательности: в теле цикла три независимые операции. На массиве из 1000 элементов разница составит 3000 шагов против 1000.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*
