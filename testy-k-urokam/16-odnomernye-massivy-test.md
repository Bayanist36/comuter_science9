# 🔑 КЛЮЧИ И КРИТЕРИИ ОЦЕНИВАНИЯ (для учителя)

### Ответы к Части А (макс. 5 баллов)

1. **б** — Нумерация начинается с нуля: первый элемент сдвинут от начала массива на ноль позиций.
2. **в** — len() возвращает количество элементов, а в списке их три, хотя индексы равны 0, 1 и 2.
3. **б** — Индексы идут от 0 до n − 1, поэтому последний элемент имеет индекс n − 1; та же ячейка доступна как a[-1].
4. **в** — При печати списка целиком Python показывает его в квадратных скобках с запятыми между элементами.
5. **в** — Допустимые индексы равны 0, 1 и 2; индекс 3 выходит за границу массива.

### Ответы к Части Б (макс. 4 балла)

**6\.** Будет выведено: 5 4 4 — первый элемент, последний элемент и количество элементов.
*Оценивание: 2 балла — ответ полный и верный; 1 балл — ответ неполный; 0 баллов — ответ неверный.*

**7\.** a[1] + a[2] = 1 + 4 = 5, значение записывается в первую ячейку, поэтому print(*a) выведет 5 1 4.
*Оценивание: 2 балла — ответ полный и верный; 1 балл — ответ неполный; 0 баллов — ответ неверный.*

### Ответы к Части В (макс. 9 баллов)

**8\.**
*Ожидаемое решение:*

Программа: a = [18, 22, 25, 17, 21, 26, 19, 23, 20, 24], затем cnt = 0, затем for i in range(len(a)): внутри if a[i] > 21: cnt += 1 и print(i + 1). Условие выполняют 22, 25, 26, 23, 24 — это дни с номерами 2, 3, 6, 8 и 10, количество равно 5. Номер дня получается как индекс плюс один, потому что индексы начинаются с нуля.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**9\.**
*Ожидаемое решение:*

Цикл начинает с i = 1 и заканчивается на i = 3, а последний допустимый индекс равен 2, поэтому на последнем шаге возникает IndexError. Первый вариант исправления — перебирать индексы от 0: for i in range(len(a)). Второй — идти по значениям без индексов: for x in a: print(x). Оба варианта выведут 6, 2 и 8.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**10\.**
*Ожидаемое решение:*

b = a не создаёт новый список: обе переменные ссылаются на один объект, поэтому изменение b[0] = 0 изменит и a[0]. Запись b = a[:] создаёт копию: срез возвращает новый список с теми же значениями. Пример: после b = a и b[0] = 0 список a станет [0, 5, 7]; если же выполнить b = a[:], а затем b[0] = 0, то b будет [0, 5, 7], а a останется [2, 5, 7].

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*
