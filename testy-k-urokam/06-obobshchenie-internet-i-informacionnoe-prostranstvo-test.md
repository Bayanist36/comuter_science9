# 🔑 КЛЮЧИ И КРИТЕРИИ ОЦЕНИВАНИЯ (для учителя)

2. **в** — Протокол стоит в начале адреса и задаёт правила обмена, в данном случае с шифрованием.

4. **в** — Настоящая служба не просит пароль по ссылке и не создаёт искусственную срочность.
5. **б** — Документ хранится на сервере, поэтому доступен с любого устройства и поддерживает совместную работу.

### Ответы к Части В (макс. 9 баллов)

**8\.**
*Ожидаемое решение:*

Протокол — https; домен — cloud.school39.ru (ru — первый уровень, school39 — домен организации, cloud — имя сервера); порт — 8443; путь — /docs/report.html; параметр — id со значением 17. При замене на http соединение станет незашифрованным: данные, включая пароль и содержимое страницы, можно перехватить и прочитать, браузер пометит сайт как небезопасный.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**9\.**
*Ожидаемое решение:*

Признаки: адрес отправителя не совпадает с доменом службы; искусственная срочность; ссылка без шифрования (http); подмена буквы в пути (loqin вместо login); просьба ввести пароль. Опасность перехода без ввода данных: страница может подставить поддельную форму, заразить устройство или зафиксировать факт активности адреса, после чего последует серия таких писем. Правильно — открыть службу вручную по известному адресу и проверить состояние аккаунта.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**10\.**
*Ожидаемое решение:*

240 МБ = 240 · 8 = 1920 Мбит; 1920 : 12 = 160 с, то есть 2 минуты 40 секунд. Хранилище: 2 ГБ = 2048 МБ; 2048 : 240 = 8,53, значит, поместятся 8 файлов (1920 МБ), девятый (2160 МБ) не влезет. Реальное время будет больше расчётного из-за служебных данных.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*
