# 🔑 КЛЮЧИ И КРИТЕРИИ ОЦЕНИВАНИЯ (для учителя)

### Ответы к Части А (макс. 5 баллов)

1. **б** — СЧЁТ учитывает только числа, а СЧЁТЗ считает все непустые ячейки, включая текст.
2. **в** — #ДЕЛ/0! появляется, когда знаменатель равен нулю или ячейка знаменателя пуста.
3. **б** — Столбец A относительный и сдвигается в B, $B фиксирован, строка 3 относительная и становится 4: =B$1*$B4.
4. **в** — ЕСЛИ проверяет условие и возвращает одно из двух значений, а счётные функции только считают.
5. **б** — Фильтр не удаляет данные, а прячет несоответствующие строки; сортировка меняет порядок всех строк.

### Ответы к Части Б (макс. 4 балла)

**6\.** Условию «не меньше 4» удовлетворяют значения 4, 5, 5 и 4 — четыре ячейки. Ответ: 4.
*Оценивание: 2 балла — ответ полный и верный; 1 балл — ответ неполный; 0 баллов — ответ неверный.*

**7\.** Второе условие 5<4 ложно, поэтому И даёт ЛОЖЬ, а ЕСЛИ возвращает «нет».
*Оценивание: 2 балла — ответ полный и верный; 1 балл — ответ неполный; 0 баллов — ответ неверный.*

### Ответы к Части В (макс. 9 баллов)

**8\.**
*Ожидаемое решение:*

Копирование сдвигает на +2 столбца и +2 строки. $B2: столбец зафиксирован, строка 2 → 4, получаем $B4. C2: столбец C → E, строка 2 → 4, получаем E4. Итог: =СУММ($B4:E4). Итог может быть неверным, если диапазон должен был охватывать фиксированный набор столбцов: при сдвиге вправо он расширяется и захватывает лишние ячейки, поэтому для копирования по строкам столбцы следовало закрепить: $B2:$E2.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**9\.**
*Ожидаемое решение:*

Информатика: (5 + 4 + 5 + 4 + 4) / 5 = 22 / 5 = 4,4; формула =СРЗНАЧ(D2:D6). Математика: (4 + 5 + 3 + 4 + 2) / 5 = 18 / 5 = 3,6; формула =СРЗНАЧ(B2:B6). Различие 0,8 балла объясняется двумя низкими оценками по математике (2 и 3), которые сильно тянут среднее вниз, тогда как по информатике нет ни одной оценки ниже 4. Среднее чувствительно к крайним значениям, поэтому при сравнении полезно смотреть и на МИН.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**10\.**
*Ожидаемое решение:*

Шаги: 1) найти артикул в прайсе поиском и сравнить с ячейкой A2 посимвольно — чаще всего мешает пробел в конце, лишний символ или другой регистр; 2) проверить типы: если в заказах артикул текст, а в прайсе число, точное совпадение не сработает; 3) убедиться, что диапазон $A$2:$C$241 действительно начинается с первого столбца прайса и не съехал. Замена ЛОЖЬ на ИСТИНА включает приблизительный поиск: #Н/Д исчезнет, но подставится значение из ближайшей меньшей строки, то есть заведомо неверная цена, и ошибка станет незаметной.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*
