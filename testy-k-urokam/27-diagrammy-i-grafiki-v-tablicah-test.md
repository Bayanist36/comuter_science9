# 🔑 КЛЮЧИ И КРИТЕРИИ ОЦЕНИВАНИЯ (для учителя)

### Ответы к Части А (макс. 5 баллов)

1. **в** — Статьи расходов в сумме дают целое, а доли целого изображает круговая диаграмма.
2. **б** — Один процент равен 3,6 градуса, поэтому 25 · 3,6 = 90.
3. **б** — Высота столбца изображает значение категории, и столбцы сравниваются между собой.
4. **в** — Легенда связывает оформление ряда (цвет, штриховку) с подписью ряда.
5. **в** — Гистограмма считает категории независимыми, а на числовой оси между значениями есть промежутки и порядок.

### Ответы к Части Б (макс. 4 балла)

**6\.** 1 — Б, 2 — В, 3 — А.
*Оценивание: 2 балла — ответ полный и верный; 1 балл — ответ неполный; 0 баллов — ответ неверный.*

**7\.** 108 / 360 = 0,3, то есть 30 процентов.
*Оценивание: 2 балла — ответ полный и верный; 1 балл — ответ неполный; 0 баллов — ответ неверный.*

### Ответы к Части В (макс. 9 баллов)

**8\.**
*Ожидаемое решение:*

Сумма 12 + 20 + 14 + 4 = 50. Доли: 12/50 = 24 % (86,4°), 20/50 = 40 % (144°), 14/50 = 28 % (100,8°), 4/50 = 8 % (28,8°). Проверка: 24 + 40 + 28 + 8 = 100 %, углы 86,4 + 144 + 100,8 + 28,8 = 360°.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**9\.**
*Ожидаемое решение:*

а) Гистограмма: сравниваются категории (секции) по количеству учеников, доли целого здесь не нужны. б) График: величина меняется по упорядоченным месяцам, важна динамика. в) Круговая: три части складываются в целое — сутки ученика, сумма долей равна 100 %.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**10\.**
*Ожидаемое решение:*

Первая: заголовок утверждает вывод о росте, хотя в данных нет ни предыдущего периода, ни процентов — заголовок должен называть то, что изображено. Вторая: подписи даны абсолютными числами, а круговая диаграмма показывает доли целого, поэтому корректно подписать проценты: 31,25 %, 43,75 %, 25 % (сумма 16 человек).

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*
