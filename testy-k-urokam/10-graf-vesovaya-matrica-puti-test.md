# 🔑 КЛЮЧИ И КРИТЕРИИ ОЦЕНИВАНИЯ (для учителя)

### Ответы к Части А (макс. 5 баллов)

1. **б** — Строка означает начало ребра, столбец — его конец.
2. **б** — Без весов каждое ребро считается за единицу длины.
3. **б** — Путь A-B-C-D-E даёт 4 + 2 + 3 + 2 = 11.
4. **в** — Входя в цикл и выходя из него, можно получать новые пути без ограничения.
5. **б** — Направление дуги задаёт допустимое движение.

### Ответы к Части Б (макс. 4 балла)

**6\.** Кратчайший путь — прямая дуга A→C длиной 4. Путь A-B-C даёт 2 + 3 = 5, то есть больше, хотя проходит через две дуги.
*Оценивание: 2 балла — ответ полный и верный; 1 балл — ответ неполный; 0 баллов — ответ неверный.*

**7\.** 3 пути: A-B-D-E, A-C-D-E, A-C-E.
*Оценивание: 2 балла — ответ полный и верный; 1 балл — ответ неполный; 0 баллов — ответ неверный.*

### Ответы к Части В (макс. 9 баллов)

**8\.**
*Ожидаемое решение:*

Матрица: A — 0, 4, 7, пусто, пусто; B — пусто, 0, 2, 6, пусто; C — пусто, пусто, 0, 3, 8; D — пусто, пусто, пусто, 0, 2; E — все пусто, 0. Пути: A-B-C-D-E = 11, A-B-D-E = 12, A-C-D-E = 12, A-B-C-E = 14, A-C-E = 15. Кратчайший — 11.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**9\.**
*Ожидаемое решение:*

Правило требует, чтобы все предшественники вершины были уже посчитаны, а в цикле каждая вершина зависит от другой по кругу: N(A) зависит от N(C), N(C) от N(B), N(B) от N(A). Такой порядок обработки построить нельзя. Кроме того, по циклу можно проходить сколько угодно раз, поэтому различных путей между вершинами бесконечно много, и конечного числа для ответа не существует.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*

**10\.**
*Ожидаемое решение:*

A-B-D-E: 5 + 2 + 1 = 8. A-C-D-E: 3 + 6 + 1 = 10. A-C-E: 3 + 7 = 10. Других путей нет. Кратчайший — A-B-D-E длиной 8.

*Оценивание: 3 балла — решение полное, с обоснованием; 2 балла — верный ход с одной неточностью; 1 балл — начато верно; 0 баллов — решение отсутствует.*
