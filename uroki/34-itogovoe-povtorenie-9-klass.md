#### 3\.2. Сети и информационная безопасность (~3 мин)

<note type="quote">
  IP-адрес — уникальный числовой адрес узла в сети, состоящий из номера сети и номера узла, границу между которыми задаёт маска подсети.
</note>

**Учитель:** Каждое устройство в сети имеет адрес. В протоколе IPv4 он записывается четырьмя числами от 0 до 255, разделёнными точками, например 192.168.10.70. Адрес состоит из двух частей: номер сети и номер узла внутри неё. Границу между ними задаёт маска подсети — ещё четыре числа, где единицы означают «это часть номера сети», а нули — «это часть номера узла».

**Учитель:** Чтобы найти адрес сети, нужно наложить маску на адрес побитово: там, где в маске единица, бит адреса остаётся, где ноль — обнуляется. Практический приём проще: маска 255.255.255.192 отводит под узлы последние 64 адреса, поэтому адрес сети всегда кратен 64. Для адреса 192.168.10.70 это 64, для 192.168.10.130 — 128.

**Учитель:** Угрозы удобно делить по цели: одни хотят получить ваши данные (фишинг, кража пароля), другие — нарушить работу (вредоносные программы), третьи пользуются вашей небрежностью (единственная копия файла). От каждой есть средство, и почти все они не требуют специальных знаний: разные пароли, двухфакторная аутентификация, обновления и резервные копии закрывают большинство бытовых рисков.

| Угроза | Как проявляется | Защита |
|:---|:---|:---|
| Фишинг | письмо просит срочно войти и подтвердить пароль | проверять адрес сайта, не переходить по ссылке из письма |
| Слабый пароль | один пароль на все сервисы, короткая строка | длинные разные пароли, менеджер паролей |
| Перехват доступа | пароль украден, второй фактор не включён | двухфакторная аутентификация |
| Вредоносная программа | файл из неизвестного источника | обновления, антивирус, проверка вложений |
| Потеря данных | единственная копия на одном диске | регулярные резервные копии |

<note type="quote">
  Замочек и HTTPS означают, что канал зашифрован, но не гарантируют честность сайта. Фишинговый сайт тоже может иметь сертификат. Проверяйте домен, а не только значок замка.
</note>

#### 3\.3. Моделирование: от объекта к модели (~3 мин)

<note type="quote">
  Модель — объект-заменитель, который сохраняет существенные для данной задачи свойства оригинала и позволяет изучать его поведение.
</note>

**Учитель:** Модель нужна, когда исследовать сам объект дорого, опасно или невозможно. Она не копирует объект целиком, а сохраняет только те свойства, которые важны для задачи: карта метро не показывает высоту домов, зато показывает пересадки. Один и тот же объект может иметь разные модели — расписание урока, схему кабинетов и список класса.

**Учитель:** Информационные модели делят по форме представления. Табличная модель упорядочивает данные по строкам и столбцам: расписание, ведомость, прайс. Графовая описывает связи: вершины и рёбра, как схема дорог или сеть друзей. Дерево — граф без циклов, удобный для перебора вариантов и для иерархий: файловая система, турнирная сетка. Математическая модель записывает зависимость формулой: путь при равномерном движении, стоимость заказа.

**Учитель:** Главная проверка модели — сравнение с реальностью. Если модель предсказывает то, что уже известно, ей можно доверять в новых условиях; если расходится, уточняют допущения. Модель с неверными допущениями даёт красивые, но бесполезные числа, и это опаснее отсутствия модели: результат выглядит убедительно.

| Вид модели | Что отражает | Пример |
|:---|:---|:---|
| Табличная | значения признаков у объектов | ведомость оценок, расписание |
| Граф | связи между объектами | схема дорог, сеть знакомств |
| Дерево | иерархию и варианты выбора | файловая система, турнир |
| Математическая | зависимость величин | формула пути, расчёт стоимости |
| Имитационная | поведение системы во времени | модель очереди, модель климата |

<note type="quote">
  Граф без стрелок означает двустороннюю связь, граф со стрелками — направленную. При подсчёте путей в направленном графе идут только по направлению стрелок, иначе получаются «пути», которых в реальности нет.
</note>

```text
Этапы компьютерного моделирования
1. Постановка задачи: что исследуем и зачем
2. Построение модели: какие свойства важны
3. Формализация: запись на языке формул, таблиц, кода
4. Программирование или расчёт
5. Эксперимент: меняем параметры, смотрим результат
6. Анализ: совпадает ли с реальностью
7. Вывод и уточнение модели
```

#### 3\.4. Алгоритмы и массивы (~3 мин)

**Учитель:** Алгоритм обладает свойствами, которые проверяют на каждом решении: дискретность, результативность, массовость и понятность исполнителю. Из конструкций собирается любая программа: следование, ветвление, цикл. Сложную задачу разбивают на подзадачи и оформляют вспомогательным алгоритмом — так решение становится короче и понятнее.

**Учитель:** Массив — это набор элементов одного типа, доступных по индексу. В Python массивом служит список: a = [12, 7, 25, 3, 18, 25]. Индексы начинаются с нуля, поэтому a[0] — это 12, а последний элемент — a[len(a)-1] или a[-1]. Почти все задачи обработки массива сводятся к четырём шаблонам: сумма, максимум или минимум, подсчёт по условию, поиск элемента.

**Учитель:** Сортировка упорядочивает массив по возрастанию или убыванию. Простая сортировка «пузырьком» сравнивает соседние элементы и меняет их местами; для полной сортировки массива из n элементов требуется n·(n−1)/2 сравнений, то есть для шести элементов 15. Встроенная функция sorted делает то же самое быстрее, но понимать принцип нужно: на нём строятся задачи про число обменов.

**Учитель:** Поток данных отличается от массива тем, что элементы не хранятся все сразу, а приходят по одному. Типовые задачи потока — найти максимум, сумму или количество по условию, не сохраняя весь набор. Тот же приём работает в электронной таблице: функция обрабатывает диапазон, не создавая промежуточных ячеек.

<note type="quote">
  Внимание на границы: при поиске максимума начальным значением берут первый элемент, а не ноль. Если все числа отрицательные, максимум, начатый с нуля, окажется неверным.
</note>

```python
a = [12, 7, 25, 3, 18, 25]
s = 0
mx = a[0]
k = 0
for x in a:
    s += x
    if x > mx:
        mx = x
    if x > 10:
        k += 1
print(s, mx, k)   # 90 25 4
```

#### 3\.5. Электронные таблицы: расчёт и проверка (~3 мин)

**Учитель:** Электронная таблица — инструмент обработки числовых данных, и её сила в связях между ячейками. Формула начинается со знака равенства и ссылается на адреса: =B2*C2. При копировании относительные адреса сдвигаются, абсолютные с долларом остаются на месте. Отсюда правило: если формула должна «ехать» по списку — адрес относительный, если должна всегда смотреть на справочник — закреплённый.

**Учитель:** Диаграмма превращает таблицу в картину: столбчатая сравнивает категории, линейная показывает изменение во времени, круговая — доли целого. Диаграмма строится по выделенному диапазону, и ошибка в диапазоне даёт правдоподобный, но неверный график.

| Вопрос к данным | Инструмент | Замечание |
|:---|:---|:---|
| Сколько числовых значений | СЧЁТ | текст не учитывает |
| Сколько непустых ячеек | СЧЁТЗ | текст учитывает |
| Сумма по условию | СУММЕСЛИ | сначала диапазон условия |
| Количество по условию | СЧЁТЕСЛИ | условие в кавычках |
| Выбор из двух вариантов | ЕСЛИ | текст в кавычках |
| Подстановка из справочника | ВПР | диапазон закрепить долларом |
| Итог по группам | сводная таблица | строки и значения |

<note type="quote">
  Коды ошибок читаются как подсказки: #ДЕЛ/0! — нулевой знаменатель, #Н/Д — значение не найдено, #ИМЯ? — опечатка в имени функции, #ССЫЛКА! — ссылка на несуществующую ячейку, ##### — число не влезает в ширину столбца.
</note>

### 4\. Самостоятельная работа (15 мин)

**Учитель:** Теперь закрепим материал. Работаем по заданиям — часть устно, часть письменно.
