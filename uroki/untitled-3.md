### Этап 3. Теоретический блок: основы создания веб-страницы и правила безопасности (8 мин)

#### 3.1. Основы структуры веб-страницы (4 мин)

**Учитель** выводит на экран минимальный шаблон HTML-страницы и комментирует:

— Веб-страница создаётся на языке **HTML** (HyperText Markup Language — язык гипертекстовой разметки). Это не язык программирования, а язык **разметки**: он описывает структуру страницы с помощью **тегов**.

**Минимальная структура веб-страницы:**

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Заголовок вкладки</title>
</head>
<body>
    <h1>Заголовок страницы</h1>
    <p>Текст абзаца.</p>
    <img src="foto.jpg" alt="Описание изображения">
    <a href="https://example.com">Ссылка</a>
</body>
</html>
```

**Учитель кратко поясняет:**
- `<!DOCTYPE html>` — объявление типа документа;
- `<html>` — корневой элемент;
- `<head>` — служебная информация (кодировка, заголовок вкладки);
- `<body>` — видимое содержимое страницы;
- `<h1>` — заголовок первого уровня;
- `<p>` — абзац;
- `<img>` — изображение;
- `<a>` — гиперссылка.

— Сегодня вы создадите простую страницу-визитку или страницу на заданную тему. Но главное — вы должны будете **проверить её на соответствие правилам информационной безопасности**.

#### 3.2. Правила информационной безопасности при создании веб-страницы (4 мин)

**Учитель** выводит на экран чек-лист и комментирует каждый пункт:

**Чек-лист безопасности при создании и публикации веб-страницы:**

| № | Правило | Пояснение |
|---|---------|-----------|
| 1 | **Не публикуйте персональные данные** | Не размещайте на странице: домашний адрес, номер телефона, номер школы, паспортные данные, геолокацию |
| 2 | **Осторожно с фотографиями** | Проверяйте, нет ли на фото случайно попавших в кадр документов, номерных знаков, адреса на конвертах; не используйте чужие фото без разрешения |
| 3 | **Не размещайте чужой контент без разрешения** | Соблюдайте авторское право. Используйте изображения с открытой лицензией или созданные самостоятельно |
| 4 | **Проверяйте ссылки** | Все гиперссылки на странице должны вести на безопасные (https://) и проверенные ресурсы. Не ссылайтесь на подозрительные сайты |
| 5 | **Не создавайте формы сбора данных без необходимости** | Если на странице есть форма обратной связи, не запрашивайте избыточные данные (пароли, номера карт, паспортные данные) |
| 6 | **Используйте защищённое соединение** | При публикации сайта убедитесь, что используется протокол HTTPS |
| 7 | **Не встраивайте подозрительный код** | Не копируйте скрипты и код с непроверенных источников — они могут содержать вредоносные элементы |
| 8 | **Подумайте о цифровом следе** | Всё, что вы публикуете, сохраняется. Оцените, не навредит ли вам этот контент в будущем |

**Учитель:**
— Этот чек-лист вы будете использовать при создании и проверке своей веб-страницы.

### Этап 4. Инструктаж по практической работе (3 мин)

**Учитель:**

— Задание на практическую работу. Вы работаете **в парах**.

**Задание:** создать простую веб-страницу на одну из тем (на выбор):
- «Моё хобби» (без указания личных данных);
- «Интересный факт из науки»;
- «Правила безопасного поведения в Интернете» (мини-памятка для сверстников);
- «Мой любимый фильм / книга / игра» (обзор без спойлеров).

**Требования к странице:**
1. Содержит заголовок (`<h1>`), не менее двух абзацев (`<p>`), не менее одного изображения (`<img>`) или одной ссылки (`<a>`).
2. Страница **не содержит** персональных данных авторов (имена можно заменить на никнеймы).
3. Все изображения и ссылки — безопасные и корректные.
4. Страница проверена по чек-листу безопасности (заполнен на раздаточном листе).

**Алгоритм работы:**
1. Открыть текстовый редактор (Блокнот / Notepad++ / VS Code).
2. Написать HTML-код страницы по шаблону.
3. Сохранить файл с расширением `.html` (например, `page.html`).
4. Открыть файл в браузере и проверить отображение.
5. Заполнить чек-лист безопасности (раздаточный лист).
6. При необходимости внести исправления.

**Учитель:**
— На работу отводится 18 минут. Если у вас возникнут вопросы по HTML-тегам — обращайтесь. Начинаем!

- Данный урок является **практическим** и завершает тему 1.1. Его главная цель — не столько научить писать HTML-код (это не предусмотрено программой как самостоятельная тема), сколько **применить знания об информационной безопасности** при создании информационного продукта.
