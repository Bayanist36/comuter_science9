### 3\. Изучение нового материала (20 мин)

**Учитель:** Почти любая обработка массива сводится к одному проходу с накопителем: суммой, максимумом, счётчиком или найденным индексом. Четыре шаблона закрывают большинство задач, а верный выбор начального значения накопителя решает, будет ли ответ правильным.

#### 3\.1. Общая схема: проход и накопитель (~4 мин)

<note type="quote">
  Накопитель — переменная, в которой по шагам собирается результат обработки массива: сумма, произведение, максимум, количество или найденный индекс.
</note>

**Учитель:** Любой типовой алгоритм обработки массива устроен одинаково: перед циклом заводят переменную-накопитель, внутри цикла её обновляют, после цикла печатают. Различаются алгоритмы только начальным значением накопителя и тем, как он обновляется. Освоив эту схему, вы перестаёте писать решение «с нуля» и начинаете узнавать в условии знакомый шаблон.

**Учитель:** Число проходов тоже важно. Если задача требует и суммы, и максимума, и количества, все три величины считают в одном цикле: лишние проходы увеличивают время работы, а на массиве в миллион элементов это заметно.

| Что ищем | Начальное значение | Обновление в цикле |
|:---|:---|:---|
| сумма | 0 | s += x |
| произведение | 1 | p *= x |
| максимум | a[0] | if x > m: m = x |
| количество по условию | 0 | if условие: c += 1 |
| признак «есть такое» | False | if условие: f = True |

<note type="quote">
  Начальное значение — не формальность. Сумма начинается с нуля, потому что ноль не меняет результат сложения; произведение — с единицы; а максимум нельзя начинать с нуля, если числа могут быть отрицательными.
</note>

```text
накопитель = начальное значение
for x in a:
    обновить накопитель
print(накопитель)
```

#### 3\.2. Сумма и среднее значение (~4 мин)

**Учитель:** Сумма — самый простой шаблон: заводим s = 0, в цикле прибавляем каждый элемент, после цикла печатаем. Среднее арифметическое получают делением суммы на количество элементов, то есть на len(a). Если массив пуст, делить не на что: программа завершится ошибкой деления на ноль, поэтому в общем случае длину проверяют.

**Учитель:** Программа выведет 60 и 12.0: сумма 10 + 4 + 22 + 8 + 16 равна 60, элементов пять, среднее 60 / 5 = 12. Обратите внимание на точку в записи 12.0 — результат деления в Python всегда вещественный, даже если делится нацело.

**Учитель:** В Python есть готовые функции sum(a), max(a), min(a) и len(a) — ими пользуются в реальных программах. Но на контрольной и на экзамене требуется написать цикл, поэтому шаблон нужно уметь воспроизводить руками, а готовые функции использовать для проверки своего ответа.

<note type="quote">
  Если нужен целый результат, используют целочисленное деление s // len(a), а если нужна точность до сотых — округление round(s / len(a), 2). Средний балл обычно округляют до десятых.
</note>

```python
a = [10, 4, 22, 8, 16]
s = 0
for x in a:
    s += x
print(s, s / len(a))
```

#### 3\.3. Минимум и максимум (~4 мин)

<note type="quote">
  Минимум (максимум) массива — элемент, значение которого не больше (не меньше) значений всех остальных элементов.
</note>

**Учитель:** Максимум ищут так: за начальное значение берут первый элемент, затем каждый следующий сравнивают с текущим максимумом и при необходимости заменяют его. Начинать с нуля нельзя: в массиве [-5, -12, -3] все числа меньше нуля, и «максимум» оказался бы нулём — числом, которого в массиве нет.

**Учитель:** Здесь вместе со значением запоминается индекс: переменная imax хранит номер ячейки, где встретился текущий максимум. Программа выведет 9 2. Поиск минимума отличается только знаком в условии: if a[i] < mn.

**Учитель:** Отдельная тонкость — пустой массив. Обращение a[0] к пустому списку даёт IndexError, поэтому поиск максимума имеет смысл только для непустого массива, и в условии задач длина обычно задана больше нуля.

<note type="quote">
  Если условие записать строгим (a[i] > mx), при нескольких одинаковых максимумах сохранится первый из них. Нестрогое условие (a[i] >= mx) сохранит последний. В задаче об этом стоит подумать заранее.
</note>

```python
a = [7, 2, 9, 4]
mx = a[0]
imax = 0
for i in range(len(a)):
    if a[i] > mx:
        mx = a[i]
        imax = i
print(mx, imax)
```

#### 3\.4. Подсчёт элементов по условию (~4 мин)

**Учитель:** Подсчёт по условию — это цикл, в котором проверяется условие, а накопитель увеличивается на единицу только при его выполнении. Тот же цикл позволяет одновременно накапливать сумму подходящих элементов: например, посчитать количество положительных чисел и их сумму. Это экономнее, чем проходить массив дважды.

**Учитель:** Положительных элементов три — 4, 7 и 9, их сумма 20, среднее 20 / 3 ≈ 6,67. На экран выводится 3 20 6.67. Ноль не считается положительным числом, поэтому он не попал ни в счётчик, ни в сумму.

**Учитель:** Условие может быть составным. Например, «числа, оканчивающиеся на 5 и большие 20» записывают так: if x % 10 == 5 and x > 20. Составное условие проверяется полностью на каждом шаге, поэтому его стоит продумать до написания цикла.

<note type="quote">
  Среднее по условию делят на счётчик cnt, а не на длину массива len(a). Для нашего примера правильный ответ 6,67, а деление на 6 дало бы 3,33 — типичная ошибка на контрольных работах.
</note>

```python
a = [4, -2, 0, 7, -1, 9]
cnt = 0
s = 0
for x in a:
    if x > 0:
        cnt += 1
        s += x
print(cnt, s, round(s / cnt, 2))
```

#### 3\.5. Линейный поиск (~4 мин)

<note type="quote">
  Линейный (последовательный) поиск — перебор элементов массива по порядку до первого совпадения с искомым значением.
</note>

**Учитель:** Линейный поиск — это перебор элементов до совпадения с искомым значением. Если элемент найден, запоминают его индекс; если после полного перебора индекс так и не изменился, значит, элемента в массиве нет. Начальное значение −1 удобно именно потому, что такого индекса не существует: его невозможно спутать с настоящей позицией.

**Учитель:** Для значения 21 сравнения идут по шагам: a[0] = 4 не подходит, a[1] = 9 не подходит, a[2] = 14 не подходит, a[3] = 21 совпало — запоминаем pos = 3 и выходим из цикла командой break. На экран выводится 3.

**Учитель:** Время поиска зависит от расположения элемента: в лучшем случае одно сравнение, в худшем — столько, сколько элементов в массиве. Для тысячи элементов худший случай требует тысячи сравнений, поэтому для больших упорядоченных массивов применяют другие алгоритмы, с которыми познакомятся позже.

<note type="quote">
  Если элемент встречается несколько раз, линейный поиск с break находит первый из них. Если нужно найти последний, break убирают: тогда цикл пройдёт целиком и pos сохранит номер последнего совпадения.
</note>

```python
a = [4, 9, 14, 21, 30]
key = 21
pos = -1
for i in range(len(a)):
    if a[i] == key:
        pos = i
        break
print(pos)
```

## Приложение: опорный конспект для доски

```
СХЕМА: накопитель + один проход
  s = НАЧАЛО
  for x in a: обновить s
  print(s)

НАЧАЛЬНЫЕ ЗНАЧЕНИЯ
  сумма 0 | произведение 1 | максимум a[0] | счётчик 0 | флаг False

СУММА        s += x              среднее s / len(a)
МАКСИМУМ     m = a[0]; if x > m: m = x
МИНИМУМ      то же, знак <
СЧЁТЧИК      if условие: c += 1
СРЕДНЕЕ ПО УСЛОВИЮ  s / cnt  (не len(a)!)
ПОИСК        pos = -1; if a[i]==key: pos=i; break

КРАЙНИЕ СЛУЧАИ: пустой массив, все отрицательные,
                элемента нет, одинаковые значения
СРАВНЕНИЙ В ПОИСКЕ: лучший 1, худший n
```
