### 3\. Изучение нового материала (20 мин)

**Учитель:** Большую задачу почти никогда не решают целиком: её делят на подзадачи, а каждую подзадачу оформляют как вспомогательный алгоритм — функцию. Функция с параметрами и результатом превращает повторяющийся код в одну строку вызова.

#### 3\.1. Зачем делить задачу на части (~4 мин)

<note type="quote">
  Декомпозиция — разбиение задачи на более простые подзадачи, каждую из которых можно решить и проверить самостоятельно.
</note>

<note type="quote">
  Вспомогательный алгоритм — алгоритм, который решает законченную часть общей задачи и вызывается по имени из другого алгоритма.
</note>

**Учитель:** Программа на сто строк, где перемешаны ввод, вычисления и вывод, работает — пока её не нужно менять. Стоит добавить одно условие, и приходится перечитывать весь текст: непонятно, где заканчивается одна часть решения и начинается другая. Опытный программист поступает иначе — сначала делит задачу на части, а потом пишет каждую часть по отдельности.

**Учитель:** Разбиение удобно вести сверху вниз, от целого к частям. Условие «найдите все трёхзначные числа, равные сумме кубов своих цифр» распадается на три подзадачи: получить цифры числа, сложить их кубы, перебрать все трёхзначные числа и сравнить результат с самим числом. Каждая подзадача формулируется одной фразой и не зависит от остальных.

**Учитель:** Хорошо выделенная подзадача годится не только для одной задачи. Функция «сумма цифр числа» понадобится и при проверке кратности, и при поиске счастливых билетов, и в задачах ОГЭ на обработку числа. Один раз написанная и проверенная часть экономит время во всех следующих программах.

| Уровень | Что на нём находится | Пример |
|:---|:---|:---|
| Задача | результат, который нужен в итоге | найти числа Армстронга |
| Подзадача | законченная часть с входом и выходом | сумма кубов цифр числа n |
| Команда | одна операция языка | n % 10, n // 10 |

<note type="quote">
  Подзадачу выделяют по смыслу, а не по числу строк. Признак настоящей подзадачи — вы можете назвать её вход (что даём) и выход (что получаем). Если назвать не получается, это пока ещё не подзадача.
</note>

#### 3\.2. Функция — вспомогательный алгоритм в Python (~4 мин)

<note type="quote">
  Функция — именованная часть программы, оформленная как вспомогательный алгоритм: у неё есть имя, параметры и, как правило, возвращаемый результат.
</note>

**Учитель:** В Python вспомогательный алгоритм оформляют как **функцию**. Описание начинается словом def, затем идут имя, круглые скобки с параметрами и двоеточие. Все команды тела записывают с отступом в четыре пробела — именно отступ показывает, что они относятся к функции.

**Учитель:** Эта функция получает число n, по одной выделяет его цифры (остаток от деления на 10), прибавляет к сумме куб каждой цифры и отбрасывает разобранную цифру целочисленным делением. Для числа 153 сумма кубов равна 1 + 125 + 27 = 153, поэтому на экран выводится 153.

**Учитель:** Имя функции выбирают по действию: sum_cubes, count_even, is_prime. Читая вызов count_even(a, b), программист сразу понимает, что получит количество чётных чисел, и ему не нужно смотреть внутрь функции.

<note type="quote">
  Тело функции — это описание, а не выполнение. Строки внутри sum_cubes не работают, пока в программе не появится вызов sum_cubes(...). Один раз описанную функцию можно вызывать сколько угодно раз.
</note>

```python
def sum_cubes(n):
    s = 0
    while n > 0:
        d = n % 10
        s += d ** 3
        n = n // 10
    return s

print(sum_cubes(153))
```

#### 3\.3. Параметры и результат: как функция общается с программой (~4 мин)

<note type="quote">
  Параметр — переменная в заголовке функции, которая получает значение аргумента при вызове.
</note>

<note type="quote">
  Аргумент — конкретное значение, которое передаётся функции при её вызове.
</note>

**Учитель:** Данные функция получает через **параметры**. В заголовке def rect_area(a, b) имена a и b — параметры, а в вызове rect_area(3, 5) числа 3 и 5 — аргументы: при вызове параметр a получает значение 3, параметр b — значение 5. Параметров может быть несколько, тогда аргументы перечисляют через запятую в том же порядке.

**Учитель:** Результат возвращают командой return. Она не только передаёт значение, но и немедленно заканчивает работу функции: команды после неё не выполняются. Если return в функции нет вовсе, вызов возвращает особое значение None, и использовать его в вычислениях нельзя.

**Учитель:** Программа выведет 16 15: периметр прямоугольника 3 на 5 равен 16, площадь — 15. Обратите внимание, что функции ничего не печатают: они возвращают числа, а печатает главная часть программы. Такое разделение позволяет использовать результат в выражении, например написать print(rect_area(3, 5) * 2).

<note type="quote">
  print(s) и return s — разные команды. Функция с print сообщает результат человеку на экране, функция с return передаёт его программе. Запись sum_cubes(153) * 2 работает только во втором случае.
</note>

```python
def rect_perimeter(a, b):
    return 2 * (a + b)

def rect_area(a, b):
    return a * b

p = rect_perimeter(3, 5)
s = rect_area(3, 5)
print(p, s)
```

#### 3\.4. Ветвление и цикл внутри функции (~4 мин)

**Учитель:** Функция — обычный алгоритм, поэтому внутри неё допустимы и ветвления, и циклы. Ветвление выбирает, какой результат вернуть: например, функция проверки чётности возвращает True для чётного аргумента и False для нечётного. Цикл нужен, когда данные надо перебрать: цифры числа, делители, элементы последовательности.

**Учитель:** Функция считает чётные числа на отрезке от a до b включительно. Цикл for перебирает все числа, ветвление if пропускает нечётные, счётчик cnt увеличивается только на чётных. Для отрезка от 10 до 20 таких чисел шесть: 10, 12, 14, 16, 18, 20 — на экран выводится 6.

**Учитель:** Внутри функции можно объявлять свои переменные — s, cnt, d. Они существуют, пока функция работает, и не мешают переменным главной программы с такими же именами: у каждой функции своя область видимости.

<note type="quote">
  return внутри цикла прерывает не только цикл, но и всю функцию. Это удобно, когда ответ уже найден (нашли делитель — выходим), и опасно, если return поставили по ошибке: тогда проверяется только первый элемент.
</note>

```python
def count_even(a, b):
    cnt = 0
    for x in range(a, b + 1):
        if x % 2 == 0:
            cnt += 1
    return cnt

print(count_even(10, 20))
```

#### 3\.5. Как собрать программу из подзадач (~4 мин)

**Учитель:** Сборка идёт в четыре шага. Сначала выписывают список подзадач с их входами и выходами. Потом пишут и проверяют каждую функцию на двух-трёх примерах вручную. Затем пишут главную часть — короткий цикл или последовательность вызовов. И только в конце проверяют программу целиком на реальных данных.

**Учитель:** Здесь подзадача «сумма цифр числа» оформлена функцией, а главная часть — четыре строки: перебор и проверка условия. Программа выводит 14, 19, 23 и 28: у числа 14 сумма цифр 5, у 19 — 10, у 23 — 5, у 28 — 10.

| Шаг | Действие | Признак, что шаг выполнен |
|:---|:---|:---|
| 1 | выписать подзадачи и их вход с выходом | у каждой части есть имя |
| 2 | написать функцию и проверить вручную | два-три примера дают верный ответ |
| 3 | собрать главную часть из вызовов | главная часть короткая |
| 4 | проверить программу целиком | ответ совпал с расчётом на бумаге |

<note type="quote">
  Проверять функцию нужно до того, как она попадёт в большую программу. Если digits_sum(10) вернула 1, ошибка внутри функции, и искать её в главном цикле бессмысленно.
</note>

```python
def digits_sum(n):
    s = 0
    while n > 0:
        s += n % 10
        n = n // 10
    return s

for x in range(10, 30):
    if digits_sum(x) % 5 == 0:
        print(x)
```

**Учитель:** Теперь закрепим материал. Работаем по заданиям — часть устно, часть письменно.

**Задание 1. Разбейте задачу на подзадачи.** Задача: «Вывести все трёхзначные числа, у которых сумма цифр равна 12». Назовите подзадачи, укажите для каждой вход и выход и определите, какая из них оформляется функцией.

**Задание 2. Запишите функцию по описанию.** Запишите функцию `last_digit(n)`, которая возвращает последнюю цифру натурального числа, и функцию `first_digit(n)`, возвращающую первую цифру (подсказка: последнюю цифру числа n можно найти как n % 10, а первую — делением на 10, пока в числе больше одной цифры).

**Задание 3. Найдите ошибку.** Ученик написал функцию для суммы цифр числа:
`def sum_digits(n): s = 0; while n > 0: s += n % 10; return s; n = n // 10`
Функция при вызове sum_digits(345) выдаёт 5. Объясните причину и исправьте программу.

**Задание 4. Что выведет программа.** Даны две функции:
`def f(a, b):` с телом `if a > b: return a - b` и второй строкой `return b - a`;
`def g(n):` с телом `s = 1`, `for i in range(1, n): s *= i`, `return s`.
Что выведет `print(f(3, 10), g(5))`?

**Задание 5. Практическая работа на компьютере.** Откройте среду Python. Наберите функцию `sum_digits(n)` из урока и проверьте её вызовом `print(sum_digits(9875))`. Затем напишите главную часть, которая для чисел от 1 до 50 выводит в одну строку через пробел те, у которых сумма цифр кратна 3. Запустите программу и запишите результат.

**Задание 6. Соберите программу из готовой функции.** Дана функция `def is_prime(n):` (возвращает True, если у числа ровно два делителя). Используя её, составьте программу, которая находит сумму всех простых чисел от 10 до 30.

**Учитель:** Проверим. Поднимите руку, у кого получился другой ответ. Разберём вместе.

*Ожидаемый ответ:* Подзадачи: 1) сумма цифр числа — вход число, выход число, оформляется функцией sum_digits(n); 2) перебор трёхзначных чисел — вход границы 100 и 999, выход последовательность; 3) проверка условия и вывод — вход число и его сумма цифр, выход строка на экране. Функцией оформляют первую подзадачу, потому что она используется многократно и имеет ясный вход и выход.

*Ожидаемый ответ:* `def last_digit(n): return n % 10`. Для первой цифры: `def first_digit(n):` с телом `while n > 10: n = n // 10` и `return n`. Проверка: last_digit(2024) = 4, first_digit(2024) = 2.

*Ожидаемый ответ:* Команда return стоит внутри цикла, поэтому функция завершается на первом же шаге и возвращает только последнюю цифру. Кроме того, строка `n = n // 10` оказалась после return и не выполняется никогда. Правильно: сначала `n = n // 10` внутри цикла, а `return s` — после цикла, без отступа. Тогда sum_digits(345) = 12.
