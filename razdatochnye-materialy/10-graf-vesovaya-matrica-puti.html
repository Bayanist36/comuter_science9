1Ключевые определения

Граф — совокупность вершин и соединяющих их рёбер.
Ориентированный граф — граф, каждое ребро которого имеет направление; направленное ребро называют дугой.
Весовая матрица графа — квадратная таблица, в которой элемент на пересечении строки i и столбца j равен весу ребра, ведущего из вершины i в вершину j.
Длина пути — сумма весов рёбер, входящих в этот путь. В невзвешенном графе длина пути равна числу его рёбер.

3Опорный конспект

ГРАФ

ВЕРШИНЫ (объекты) + РЁБРА (связи)
  ориентированный: дуги A->B, порядок важен
  взвешенный: у ребра есть число (вес)
  ациклический: нет циклов, есть порядок вершин

ВЕСОВАЯ МАТРИЦА: строка - откуда, столбец - куда
  диагональ 0 | пусто = ребра нет
  неориентированный -> симметрична

ДЛИНА ПУТИ = СУММА ВЕСОВ его рёбер
  кратчайший путь: перебрать все, взять минимум

ЧИСЛО ПУТЕЙ (только в ациклическом графе!)
  N(A) = 1

1Ответы к заданиям

Задание 1. Строки и столбцы A, B, C, D: A — 0, 4, 2, пусто; B — 4, 0, 1, 7; C — 2, 1, 0, 6; D — пусто, 7, 6, 0. Матрица симметрична, потому что ребро одно и то же в обе стороны: вес из A в B равен весу из B в A.

Задание 2. A-C-D: 2 + 6 = 8. A-C-B-D: 2 + 1 + 7 = 10. A-B-D: 4 + 7 = 11. A-B-C-D: 4 + 1 + 6 = 11. Кратчайший — A-C-D, длина 8.

Задание 3. N(A) = 1, N(B) = 1, N(C) = 1, N(D) = N(B) + N(C) = 2, N(E) = N(C) + N(D) = 1 + 2 = 3. Пути: A-B-D-E, A-C-D-E, A-C-E.

Задание 4. В ориентированном графе обратной дуги B→A нет, поэтому клетка (B, A) должна быть пустой. Симметричное заполнение придумало ребро, которого нет, и привело к ложному пути. Матрицу нужно заполнять только по дугам: (A, B) = 3, (A, C) = 9, (B, C) = 4, остальные клетки пустые.
