1Ключевые определения

Управление — целенаправленное воздействие одних объектов на другие, которое приводит объект управления в требуемое состояние.
Сигнал — физический процесс, который несёт информацию и может быть принят, преобразован и использован для управления.
Разомкнутая система управления — система, в которой управляющее воздействие вырабатывается без использования информации о фактическом состоянии объекта.
Обратная связь — информация о фактическом состоянии объекта управления, которая поступает в управляющую систему и используется для выработки дальнейших воздействий.

3Опорный конспект

УПРАВЛЕНИЕ — целенаправленное воздействие
  управляющая система  -->  объект управления
  цель = требуемое состояние объекта

СИГНАЛ — физический процесс, несущий информацию
  непрерывный (плавно) | дискретный (набор значений)
  ДАТЧИК: величина -> сигнал (напряжение, код)

РАЗОМКНУТАЯ:  управление -> объект        (нет контроля)
  будильник, светофор по таймеру, таймер печи
  ошибка не видна и не исправляется

ЗАМКНУТАЯ: управление -> объект -> ДАТЧИК -> сравнение с целью
  утюг, кондиционер, автопилот, круиз-контроль
  ОБРАТНАЯ СВЯЗЬ: результат возвращается на вход
