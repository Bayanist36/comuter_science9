1Ключевые определения

Декомпозиция — разбиение задачи на более простые подзадачи, каждую из которых можно решить и проверить самостоятельно.
Вспомогательный алгоритм — алгоритм, который решает законченную часть общей задачи и вызывается по имени из другого алгоритма.
Функция — именованная часть программы, оформленная как вспомогательный алгоритм: у неё есть имя, параметры и, как правило, возвращаемый результат.
Параметр — переменная в заголовке функции, которая получает значение аргумента при вызове.

1Ответы к заданиям

Задание 1. Подзадачи: 1) сумма цифр числа — вход число, выход число, оформляется функцией sum_digits(n); 2) перебор трёхзначных чисел — вход границы 100 и 999, выход последовательность; 3) проверка условия и вывод — вход число и его сумма цифр, выход строка на экране. Функцией оформляют первую подзадачу, потому что она используется многократно и имеет ясный вход и выход.

Задание 2. def last_digit(n): return n % 10. Для первой цифры: def first_digit(n): с телом while n > 10: n = n // 10 и return n. Проверка: last_digit(2024) = 4, first_digit(2024) = 2.

Задание 3. Команда return стоит внутри цикла, поэтому функция завершается на первом же шаге и возвращает только последнюю цифру. Кроме того, строка n = n // 10 оказалась после return и не выполняется никогда. Правильно: сначала n = n // 10 внутри цикла, а return s — после цикла, без отступа. Тогда sum_digits(345) = 12.

Задание 4. f(3, 10): условие 3 > 10 ложно, поэтому выполняется return b - a = 10 - 3 = 7. g(5) перемножает числа 1, 2, 3, 4 и возвращает 24. На экран будет выведено: 7 24.
