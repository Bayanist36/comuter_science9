1Ключевые определения

Диаграмма — графическое представление числовых данных, в котором значения величин изображаются геометрическими фигурами: столбцами, полосами, секторами, точками или линиями.
Гистограмма — диаграмма, в которой каждое значение изображается вертикальным столбцом, а высота столбца пропорциональна значению.

3Опорный конспект

ДИАГРАММА = геометрический образ ряда данных
ряд: КАТЕГОРИЯ + ЗНАЧЕНИЕ

ВЫБОР ТИПА ПО ВОПРОСУ
  сколько? чего больше?      -> ГИСТОГРАММА
  длинные названия, рейтинг   -> ЛИНЕЙЧАТАЯ
  какая доля целого?          -> КРУГОВАЯ (одна серия)
  как меняется во времени?    -> ГРАФИК
  связаны ли две величины?    -> ТОЧЕЧНАЯ

КРУГОВАЯ
  целое = 100 % = 360 градусов
  угол = значение / сумма * 360
  сумма долей = 100 %, сумма углов = 360

ОФОРМЛЕНИЕ: заголовок | оси + единицы | легенда | подписи

1Ответы к заданиям

Задание 1. а) гистограмма — сравнение категорий по количеству; б) круговая — доли одного целого (весь объём подготовки); в) график или гистограмма — изменение по упорядоченным дням; г) точечная — две числовые величины, ищем зависимость.

Задание 2. а) апрель, 160; б) (160 − 98) / 98 · 100 ≈ 63,3 %; в) сумма 120 + 145 + 98 + 160 = 523, доля марта 98 / 523 ≈ 18,7 %.

Задание 3. 25 % (90°), 40 % (144°), 30 % (108°), 5 % (18°). Сумма процентов 100, сумма углов 360°.

Задание 4. Первая ошибка: круговая диаграмма не предназначена для нескольких рядов, секторы разных рядов смешиваются. Вторая: сумма долей не может превышать 100 процентов, значит, диапазон захватил лишние ячейки или итоговую строку. Правильно: построить две отдельные круговые диаграммы либо одну гистограмму с двумя рядами и легендой.
