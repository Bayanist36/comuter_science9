1Ответы к заданиям

Задание 1. Шаг 1: x = 6, total = 6, count = 1, min = 6, max = 6. Шаг 2: x = −3, total = 3, count = 2, min = −3, max = 6. Шаг 3: x = 14, total = 17, count = 3, min = −3, max = 14. Шаг 4: x = 0 — сторож, остановка. Итог: сумма 17, количество 3, минимум −3, максимум 14, среднее 17/3 ≈ 5,67.

Задание 2. Нужны две переменные: total и count; после цикла — проверка if count > 0: print(total / count) else: print("данных нет"). Если первым придёт ноль, цикл сразу прервётся, count = 0, и без проверки произойдёт деление на ноль — программа завершится с ошибкой. С проверкой будет выведено «данных нет».

Задание 3. Верный максимум равен −1. Начальное значение 0 больше любого элемента данных, поэтому условие «элемент больше текущего максимума» ни разу не выполнится при строгом сравнении, и в ответе останется число, которого в данных не было. Для минимума ноль случайно оказался безвредным: любое отрицательное число меньше нуля, и рекорд обновляется. Надёжное решение одно — брать начальное значение у первого элемента…

Задание 4. Лучше использовать количество: for i in range(1440). Ноль не подходит как сторож, потому что 0 °C — реальное допустимое измерение, и первое же такое значение оборвало бы обработку, потеряв остальные данные. Сторожевое значение должно быть невозможным в данных, а для температуры такого удобного числа нет.
