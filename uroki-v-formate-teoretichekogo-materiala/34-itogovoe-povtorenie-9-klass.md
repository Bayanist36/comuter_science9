## 3\. Сети и информационная безопасность

> **Определение.** IP-адрес — уникальный числовой адрес узла в сети, состоящий из номера сети и номера узла, границу между которыми задаёт маска подсети.

Каждое устройство в сети имеет адрес. В протоколе IPv4 он записывается четырьмя числами от 0 до 255, разделёнными точками, например 192.168.10.70. Адрес состоит из двух частей: номер сети и номер узла внутри неё. Границу между ними задаёт маска подсети — ещё четыре числа, где единицы означают «это часть номера сети», а нули — «это часть номера узла».

Чтобы найти адрес сети, нужно наложить маску на адрес побитово: там, где в маске единица, бит адреса остаётся, где ноль — обнуляется. Практический приём проще: маска 255.255.255.192 отводит под узлы последние 64 адреса, поэтому адрес сети всегда кратен 64. Для адреса 192.168.10.70 это 64, для 192.168.10.130 — 128.

Угрозы удобно делить по цели: одни хотят получить ваши данные (фишинг, кража пароля), другие — нарушить работу (вредоносные программы), третьи пользуются вашей небрежностью (единственная копия файла). От каждой есть средство, и почти все они не требуют специальных знаний: разные пароли, двухфакторная аутентификация, обновления и резервные копии закрывают большинство бытовых рисков.

| Угроза | Как проявляется | Защита |
|:---|:---|:---|
| Фишинг | письмо просит срочно войти и подтвердить пароль | проверять адрес сайта, не переходить по ссылке из письма |
| Слабый пароль | один пароль на все сервисы, короткая строка | длинные разные пароли, менеджер паролей |
| Перехват доступа | пароль украден, второй фактор не включён | двухфакторная аутентификация |
| Вредоносная программа | файл из неизвестного источника | обновления, антивирус, проверка вложений |
| Потеря данных | единственная копия на одном диске | регулярные резервные копии |

> Замочек и HTTPS означают, что канал зашифрован, но не гарантируют честность сайта. Фишинговый сайт тоже может иметь сертификат. Проверяйте домен, а не только значок замка.

## 4\. Моделирование: от объекта к модели

> **Определение.** Модель — объект-заменитель, который сохраняет существенные для данной задачи свойства оригинала и позволяет изучать его поведение.

Модель нужна, когда исследовать сам объект дорого, опасно или невозможно. Она не копирует объект целиком, а сохраняет только те свойства, которые важны для задачи: карта метро не показывает высоту домов, зато показывает пересадки. Один и тот же объект может иметь разные модели — расписание урока, схему кабинетов и список класса.

Информационные модели делят по форме представления. Табличная модель упорядочивает данные по строкам и столбцам: расписание, ведомость, прайс. Графовая описывает связи: вершины и рёбра, как схема дорог или сеть друзей. Дерево — граф без циклов, удобный для перебора вариантов и для иерархий: файловая система, турнирная сетка. Математическая модель записывает зависимость формулой: путь при равномерном движении, стоимость заказа.

Главная проверка модели — сравнение с реальностью. Если модель предсказывает то, что уже известно, ей можно доверять в новых условиях; если расходится, уточняют допущения. Модель с неверными допущениями даёт красивые, но бесполезные числа, и это опаснее отсутствия модели: результат выглядит убедительно.

| Вид модели | Что отражает | Пример |
|:---|:---|:---|
| Табличная | значения признаков у объектов | ведомость оценок, расписание |
| Граф | связи между объектами | схема дорог, сеть знакомств |
| Дерево | иерархию и варианты выбора | файловая система, турнир |
| Математическая | зависимость величин | формула пути, расчёт стоимости |
| Имитационная | поведение системы во времени | модель очереди, модель климата |

> Граф без стрелок означает двустороннюю связь, граф со стрелками — направленную. При подсчёте путей в направленном графе идут только по направлению стрелок, иначе получаются «пути», которых в реальности нет.

```text
Этапы компьютерного моделирования
1. Постановка задачи: что исследуем и зачем
2. Построение модели: какие свойства важны
3. Формализация: запись на языке формул, таблиц, кода
4. Программирование или расчёт
5. Эксперимент: меняем параметры, смотрим результат
6. Анализ: совпадает ли с реальностью
7. Вывод и уточнение модели
```

## 5\. Алгоритмы и массивы

Алгоритм обладает свойствами, которые проверяют на каждом решении: дискретность, результативность, массовость и понятность исполнителю. Из конструкций собирается любая программа: следование, ветвление, цикл. Сложную задачу разбивают на подзадачи и оформляют вспомогательным алгоритмом — так решение становится короче и понятнее.

Массив — это набор элементов одного типа, доступных по индексу. В Python массивом служит список: a = [12, 7, 25, 3, 18, 25]. Индексы начинаются с нуля, поэтому a[0] — это 12, а последний элемент — a[len(a)-1] или a[-1]. Почти все задачи обработки массива сводятся к четырём шаблонам: сумма, максимум или минимум, подсчёт по условию, поиск элемента.

Сортировка упорядочивает массив по возрастанию или убыванию. Простая сортировка «пузырьком» сравнивает соседние элементы и меняет их местами; для полной сортировки массива из n элементов требуется n·(n−1)/2 сравнений, то есть для шести элементов 15. Встроенная функция sorted делает то же самое быстрее, но понимать принцип нужно: на нём строятся задачи про число обменов.

Поток данных отличается от массива тем, что элементы не хранятся все сразу, а приходят по одному. Типовые задачи потока — найти максимум, сумму или количество по условию, не сохраняя весь набор. Тот же приём работает в электронной таблице: функция обрабатывает диапазон, не создавая промежуточных ячеек.

> Внимание на границы: при поиске максимума начальным значением берут первый элемент, а не ноль. Если все числа отрицательные, максимум, начатый с нуля, окажется неверным.

```python
a = [12, 7, 25, 3, 18, 25]
s = 0
mx = a[0]
k = 0
for x in a:
    s += x
    if x > mx:
        mx = x
    if x > 10:
        k += 1
print(s, mx, k)   # 90 25 4
```

## 6\. Электронные таблицы: расчёт и проверка

Электронная таблица — инструмент обработки числовых данных, и её сила в связях между ячейками. Формула начинается со знака равенства и ссылается на адреса: =B2*C2. При копировании относительные адреса сдвигаются, абсолютные с долларом остаются на месте. Отсюда правило: если формула должна «ехать» по списку — адрес относительный, если должна всегда смотреть на справочник — закреплённый.

Диаграмма превращает таблицу в картину: столбчатая сравнивает категории, линейная показывает изменение во времени, круговая — доли целого. Диаграмма строится по выделенному диапазону, и ошибка в диапазоне даёт правдоподобный, но неверный график.

| Вопрос к данным | Инструмент | Замечание |
|:---|:---|:---|
| Сколько числовых значений | СЧЁТ | текст не учитывает |
| Сколько непустых ячеек | СЧЁТЗ | текст учитывает |
| Сумма по условию | СУММЕСЛИ | сначала диапазон условия |
| Количество по условию | СЧЁТЕСЛИ | условие в кавычках |
| Выбор из двух вариантов | ЕСЛИ | текст в кавычках |
| Подстановка из справочника | ВПР | диапазон закрепить долларом |
| Итог по группам | сводная таблица | строки и значения |

> Коды ошибок читаются как подсказки: #ДЕЛ/0! — нулевой знаменатель, #Н/Д — значение не найдено, #ИМЯ? — опечатка в имени функции, #ССЫЛКА! — ссылка на несуществующую ячейку, ##### — число не влезает в ширину столбца.

## 7\. Разобранные примеры

### Пример 1. Адрес сети по IP-адресу и маске

**Условие.** Узел имеет адрес 192.168.10.70 и маску 255.255.255.192. Найдите адрес сети, широковещательный адрес и число доступных узлов.

**Решение.** Маска 255.255.255.192 в последнем октете равна 11000000₂, то есть под номер узла отведено 6 бит: 2⁶ = 64 адреса в подсети. Адрес сети кратен 64: ближайшее число, не большее 70, — это 64. Значит, сеть 192.168.10.64, широковещательный адрес — последний в блоке, 192.168.10.127. Доступных узлов: 64 − 2 = 62, потому что первый адрес занят сетью, последний — широковещательным.

**Ответ:** сеть 192.168.10.64, широковещательный адрес 192.168.10.127, доступно 62 узла.

### Пример 2. Полная обработка массива

**Условие.** Дан массив a = [12, 7, 25, 3, 18, 25]. Найдите сумму элементов, максимальный элемент и количество элементов, больших 10. Сколько сравнений потребует сортировка «пузырьком»?

**Решение.** Сумма: 12 + 7 + 25 + 3 + 18 + 25 = 90. Максимум ищем перебором: 12, затем 25, дальше значения не превышают его — максимум 25, причём встречается дважды. Элементы больше 10: 12, 25, 18, 25 — четыре. Сортировка «пузырьком» для n = 6 делает n·(n−1)/2 = 6·5/2 = 15 сравнений. После сортировки массив примет вид [3, 7, 12, 18, 25, 25].

**Ответ:** сумма 90, максимум 25 (два раза), элементов больше 10 — четыре, сравнений 15.

### Пример 3. Формулы по ведомости

**Условие.** В таблице строки 2–6: A — фамилия, B — класс, C — балл. Значения: Антонов 9А 5, Борисова 9Б 4, Власов 9А 3, Гусева 9А 4, Дёмин 9Б 5. Что вернут формулы: =СУММЕСЛИ(B2:B6;"9А";C2:C6), =СРЗНАЧ(C2:C6), =СЧЁТЕСЛИ(C2:C6;">=4") и =ЕСЛИ(C4>=4;"зачёт";"незачёт")?

**Решение.** СУММЕСЛИ берёт строки класса 9А: 5 + 3 + 4 = 12. СРЗНАЧ считает все пять баллов: 21 : 5 = 4,2. СЧЁТЕСЛИ с условием «не меньше 4» находит 5, 4, 4, 5 — четыре значения. ЕСЛИ смотрит на C4, где стоит балл Власова 3: условие 3 ≥ 4 ложно, значит, результат «незачёт».

**Ответ:** 12; 4,2; 4; «незачёт».
