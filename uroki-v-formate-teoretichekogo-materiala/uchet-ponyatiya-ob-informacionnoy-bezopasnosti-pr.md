## 1\. От потребителя к автору: создание контента в Интернете

### 1\.1. Два типа активности в сети

На предыдущих уроках мы рассматривали Интернет преимущественно с позиции **пользователя-потребителя**: вы ищете информацию, просматриваете сайты, пользуетесь сервисами, общаетесь в мессенджерах. В этой роли главная задача безопасности -- защитить себя от внешних угроз: фишинга, вредоносного ПО, кибербуллинга.

Однако в современном Интернете каждый пользователь может стать **автором и публикатором** информации:

-  создать страницу в социальной сети и выложить фотографии;

-  написать пост в блоге или на форуме;

-  загрузить видео на видеохостинг;

-  создать веб-сайт или веб-страницу;

-  опубликовать документ в облачном хранилище с общим доступом;

-  участвовать в совместном редактировании документов.

<note type="quote">

**Важно.** Когда вы создаёте и публикуете контент, вы несёте ответственность не только за свою безопасность, но и за безопасность тех, кто будет с вашим контентом взаимодействовать.

</note>

### 1\.2. Методы индивидуального и коллективного размещения информации

| Метод                          | Примеры                                                                      | Характер                                     |
|--------------------------------|------------------------------------------------------------------------------|----------------------------------------------|
| **Индивидуальное размещение**  | Личный блог, страница в соцсети, личный сайт, видеоканал                     | Один автор управляет контентом               |
| **Коллективное размещение**    | Вики-проекты, совместные документы, групповые чаты, командные облачные папки | Несколько авторов работают с общим контентом |
| **Публикация через платформу** | Размещение материалов на готовых сервисах (конструкторы сайтов, хостинги)    | Автор пользуется чужой инфраструктурой       |

Каждый из этих методов имеет свои особенности с точки зрения информационной безопасности.

## 2\. Основы структуры веб-страницы

### 2\.1. Что такое веб-страница

**Веб-страница** -- это документ, написанный на языке разметки **HTML** (HyperText Markup Language), который браузер интерпретирует и отображает пользователю в виде текста, изображений, ссылок и других элементов.

**Веб-сайт** -- это совокупность связанных веб-страниц, объединённых общим доменным именем и тематикой.

### 2\.2. Язык HTML: основные понятия

HTML -- это не язык программирования, а **язык разметки**. Он не содержит алгоритмов и вычислений, а описывает **структуру** страницы с помощью **тегов**.

<note type="quote">

**Определение.** **Тег** -- это специальная команда в угловых скобках, которая указывает браузеру, как отобразить тот или иной элемент страницы.

</note>

Большинство тегов являются **парными**: они состоят из открывающего и закрывающего тега:

```
<тег> содержимое </тег>
```

Например: `<p>Это текст абзаца.</p>`

### 2\.3. Минимальная структура HTML-документа

```
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Заголовок вкладки браузера</title>
</head>
<body>
    <!-- Видимое содержимое страницы -->
    <h1>Главный заголовок</h1>
    <p>Текст абзаца.</p>
</body>
</html>
```

| Элемент                  | Назначение                                                             |
|--------------------------|------------------------------------------------------------------------|
| `<!DOCTYPE html>`        | Объявление типа документа (сообщает браузеру, что это HTML5)           |
| `<html>`                 | Корневой элемент, содержит всю страницу                                |
| `<head>`                 | Служебная информация: кодировка, заголовок вкладки, подключение стилей |
| `<meta charset="UTF-8">` | Указание кодировки (для корректного отображения кириллицы)             |
| `<title>`                | Текст, отображаемый на вкладке браузера                                |
| `<body>`                 | Видимое содержимое страницы                                            |

### 2\.4. Основные теги содержимого

| Тег                       | Назначение                                    | Пример                                                                             |
|---------------------------|-----------------------------------------------|------------------------------------------------------------------------------------|
| `<h1>` -- `<h6>`          | Заголовки (от крупнейшего к мельчайшему)      | `<h1>Название раздела</h1>`                                                        |
| `<p>`                     | Абзац текста                                  | `<p>Текст абзаца.</p>`                                                             |
| `<a>`                     | Гиперссылка                                   | `<a href="`[`https://example.com">Текст`](https://example.com">Текст) `ссылки</a>` |
| `<img>`                   | Изображение                                   | `<img src="foto.jpg" alt="Описание">`                                              |
| `<ul>`, `<ol>`, `<li>`    | Списки (маркированный, нумерованный, элемент) | `<ul><li>Пункт</li></ul>`                                                          |
| `<table>`, `<tr>`, `<td>` | Таблица, строка, ячейка                       | `<table><tr><td>Данные</td></tr></table>`                                          |
| `<strong>`                | Полужирный текст (важность)                   | `<strong>Важно!</strong>`                                                          |
| `<em>`                    | Курсивный текст (акцент)                      | `<em>Обратите внимание</em>`                                                       |

### 2\.5. Атрибуты тегов

Теги могут иметь **атрибуты** -- дополнительные параметры, уточняющие их поведение:

-  Атрибут `href` у тега `<a>` задаёт адрес ссылки.

-  Атрибут `src` у тега `<img>` задаёт путь к файлу изображения.

-  Атрибут `alt` у тега `<img>` задаёт альтернативный текст (отображается, если изображение не загрузилось; используется программами чтения с экрана для незрячих пользователей).

## 3\. Правила информационной безопасности при создании веб-контента

### 3\.1. Защита персональных данных автора

При создании веб-страницы, блога или профиля в социальной сети необходимо помнить о **цифровом следе**: всё, что вы публикуете, сохраняется и может быть использовано третьими лицами.

**Что НЕ следует публиковать на веб-странице:**

| Категория данных            | Примеры                           | Риск                                            |
|-----------------------------|-----------------------------------|-------------------------------------------------|
| Идентификационные данные    | Полное ФИО, дата рождения         | Кража личности, мошенничество                   |
| Контактные данные           | Домашний адрес, номер телефона    | Преследование, нежелательные контакты           |
| Данные об учебном заведении | Номер школы, класс, расписание    | Определение местонахождения несовершеннолетнего |
| Документы                   | Паспорт, СНИЛС, ученический билет | Оформление кредитов, мошенничество              |
| Данные о местоположении     | Геолокация на фото, геометки      | Отслеживание перемещений                        |
| Финансовые данные           | Номера карт, счетов               | Кража денежных средств                          |

**Что допустимо публиковать:**

-  Никнейм (псевдоним) вместо реального имени.

-  Обобщённую информацию: «я увлекаюсь программированием» вместо «я учусь в школе № 108, класс 9Б».

-  Изображения, не содержащие случайно попавших в кадр личных данных.

### 3\.2. Безопасность изображений

Фотографии и изображения, размещаемые на веб-странице, требуют особого внимания:

1. **Проверяйте фон.** На фотографии случайно могут оказаться: адрес на конверте, номер автомобиля, документы на столе, экран монитора с открытым сайтом, номер школы на форме.

2. **Удаляйте метаданные (EXIF).** Цифровые фотографии часто содержат скрытые данные: дату и время съёмки, модель устройства, **координаты GPS**. Перед публикацией метаданные рекомендуется удалять.

3. **Уважайте авторское право.** Не используйте чужие фотографии и изображения без разрешения автора. Используйте:

   -  собственные фотографии;

   -  изображения с открытой лицензией (Creative Commons);

   -  бесплатные фотобанки (с указанием условий использования).

### 3\.3. Безопасность ссылок

Гиперссылки на вашей странице ведут посетителей на другие ресурсы. Вы несёте ответственность за то, куда направляет посетителей ваш контент.

**Правила:**

-  Ссылайтесь только на проверенные, известные ресурсы.

-  Проверяйте, что ссылка ведёт на сайт с протоколом **HTTPS** (защищённое соединение).

-  Не размещайте ссылки на сайты с подозрительным содержанием, вредоносным ПО или незаконным контентом.

-  Проверяйте работоспособность ссылок перед публикацией.

### 3\.4. Безопасность форм и сбора данных

Если ваша веб-страница содержит **форму** (например, форму обратной связи, форму регистрации, форму опроса):

-  **Запрашивайте минимум данных.** Если для обратной связи достаточно имени и сообщения -- не запрашивайте номер телефона, адрес, дату рождения.

-  **Никогда не запрашивайте** в формах: пароли, данные банковских карт, паспортные данные, коды из СМС.

-  **Предупреждайте пользователя**, какие данные вы собираете и зачем.

-  **Не храните** собранные данные в открытом доступе.

### 3\.5. Защита от вредоносного кода

При создании веб-страницы:

-  **Не копируйте код** (скрипты, виджеты, баннеры) с непроверенных источников. Они могут содержать скрытый вредоносный код.

-  **Не встраивайте** на страницу элементы, происхождение которых вам неизвестно.

-  Если вы используете конструктор сайтов или платформу для публикации, убедитесь в её **репутации и защищённости**.

-  При использовании сторонних библиотек или шаблонов скачивайте их только с **официальных сайтов разработчиков**.

### 3\.6. Защита контента от несанкционированного доступа

Если вы создаёте страницу или документ с ограниченным доступом (например, для учебной группы):

-  Используйте **надёжные пароли** для защиты доступа.

-  Включите **двухфакторную аутентификацию**, если платформа это позволяет.

-  Не передавайте пароли от аккаунтов третьим лицам.

-  Регулярно проверяйте **список пользователей**, имеющих доступ к вашему контенту.

## 4\. Авторское право и этика публикации

### 4\.1. Авторское право в цифровом пространстве

<note type="quote">

**Определение.** **Авторское право** -- совокупность правовых норм, регулирующих отношения, связанные с созданием и использованием произведений науки, литературы и искусства.

</note>

В Российской Федерации авторское право регулируется **частью 4 Гражданского кодекса РФ**.

**Что это значит для создателя веб-страницы:**

| Ситуация                                      | Правило                                                              |
|-----------------------------------------------|----------------------------------------------------------------------|
| Вы используете чужое изображение              | Необходимо разрешение автора или свободная лицензия                  |
| Вы цитируете чужой текст                      | Указывайте источник и автора; объём цитирования должен быть разумным |
| Вы создаёте оригинальный контент              | Вы являетесь автором и обладаете правами на него                     |
| Вы размещаете контент под свободной лицензией | Указывайте условия использования (например, Creative Commons)        |

### 4\.2. Свободные лицензии

**Лицензии Creative Commons** позволяют авторам разрешать использование своих произведений на определённых условиях:

| Лицензия     | Условия                                                                                        |
|--------------|------------------------------------------------------------------------------------------------|
| **CC BY**    | Можно использовать при условии указания автора                                                 |
| **CC BY-SA** | Можно использовать и изменять при условии указания автора и распространения на тех же условиях |
| **CC BY-NC** | Можно использовать в некоммерческих целях с указанием автора                                   |
| **CC0**      | Автор отказался от всех прав; произведение в общественном достоянии                            |

### 4\.3. Этические нормы публикации

Помимо правовых норм, при создании контента следует соблюдать **этические принципы**:

-  Не публикуйте информацию, которая может причинить вред другим людям.

-  Не размещайте оскорбительный, дискриминационный или экстремистский контент.

-  Не распространяйте непроверенную информацию как факт.

-  Уважайте приватность других людей: не публикуйте их фото, переписку или личные данные без согласия.

-  Помечайте рекламу и спонсорские материалы.

## 5\. Безопасность при коллективной работе над веб-контентом

### 5\.1. Особенности коллективного размещения

При совместном создании контента (например, групповой проект, общая вики-страница, совместный документ) возникают дополнительные вопросы безопасности:

-  **Разграничение доступа.** Определите, кто может редактировать, кто -- только просматривать.

-  **История изменений.** Используйте платформы, сохраняющие историю правок, чтобы можно было отследить, кто и что изменил.

-  **Общие пароли.** Если для доступа к платформе используется общий аккаунт, пароль должен быть надёжным и не передаваться за пределы группы.

-  **Ответственность.** При коллективной публикации ответственность за контент несут все участники.

### 5\.2. Облачные сервисы и совместная работа

При использовании облачных сервисов для совместной работы над документами:

-  Проверяйте **настройки доступа**: по ссылке (кто угодно) или только для приглашённых пользователей.

-  Не делитесь ссылкой на документ в открытом доступе, если он содержит конфиденциальную информацию.

-  По завершении проекта **закрывайте доступ** для тех, кому он больше не нужен.

## 6\. Чек-лист безопасности веб-страницы

Обобщим все правила в виде единого чек-листа, который можно использовать при создании и проверке любой веб-страницы:

| №  | Критерий проверки                                                                   | Статус |
|----|-------------------------------------------------------------------------------------|--------|
| 1  | На странице отсутствуют персональные данные автора (ФИО, адрес, телефон, школа)     | ☐      |
| 2  | Изображения не содержат случайно попавших личных данных (документы, адреса, экраны) | ☐      |
| 3  | Метаданные изображений (геолокация, данные устройства) удалены                      | ☐      |
| 4  | Все изображения легальны: собственные или со свободной лицензией                    | ☐      |
| 5  | Все гиперссылки ведут на безопасные (HTTPS) и проверенные ресурсы                   | ☐      |
| 6  | На странице нет ссылок на подозрительные или вредоносные сайты                      | ☐      |
| 7  | Формы (если есть) не запрашивают избыточные данные                                  | ☐      |
| 8  | На странице нет форм, запрашивающих пароли или данные карт                          | ☐      |
| 9  | Контент не содержит оскорблений, агрессии, экстремистских материалов                | ☐      |
| 10 | Контент не нарушает авторских прав третьих лиц                                      | ☐      |
| 11 | Встроенный код (скрипты, виджеты) взят из проверенных источников                    | ☐      |
| 12 | Публикация этой страницы не создаст рисков для автора в будущем                     | ☐      |

## 7\. Практический пример: анализ веб-страницы

Рассмотрим пример учебной веб-страницы и проверим её на соответствие правилам безопасности.

**Страница «Моё хобби -- робототехника»:**

```
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Робототехника</title>
</head>
<body>
    <h1>Моё хобби — робототехника</h1>
    <p>Я увлекаюсь конструированием роботов уже три года.
       Мне нравится программировать датчики и моторы.</p>
    <img src="robot.jpg" alt="Мой первый робот на соревнованиях">
    <p>Больше информации о робототехнике можно найти на сайте
       <a href="https://robolymp.ru">Робоолимпиада</a>.</p>
</body>
</html>
```

**Анализ по чек-листу:**

| Критерий            | Результат                                                               |
|---------------------|-------------------------------------------------------------------------|
| Персональные данные | ✅ Нет ФИО, адреса, телефона, школы                                      |
| Изображение         | ⚠️ Нужно проверить: нет ли на фото личных данных, удалены ли метаданные |
| Ссылка              | ✅ Ведёт на известный ресурс, протокол HTTPS                             |
| Авторское право     | ⚠️ Нужно убедиться, что фото собственное или со свободной лицензией     |
| Формы               | ✅ Формы отсутствуют                                                     |
| Вредоносный код     | ✅ Нет встроенных скриптов из неизвестных источников                     |

**Вывод:** страница в целом безопасна, но перед публикацией необходимо проверить изображение на наличие метаданных и убедиться в соблюдении авторских прав.

## 8\. Ключевые термины урока

| Термин                | Определение                                                                       |
|-----------------------|-----------------------------------------------------------------------------------|
| Веб-страница          | Документ на языке HTML, отображаемый браузером                                    |
| Веб-сайт              | Совокупность связанных веб-страниц, объединённых доменным именем                  |
| HTML                  | Язык гипертекстовой разметки для создания структуры веб-страниц                   |
| Тег                   | Команда в угловых скобках, определяющая элемент страницы                          |
| Атрибут               | Дополнительный параметр тега, уточняющий его свойства                             |
| Гиперссылка           | Элемент, обеспечивающий переход на другой ресурс                                  |
| Метаданные (EXIF)     | Скрытая информация в файле: дата съёмки, устройство, геолокация                   |
| Авторское право       | Правовые нормы, защищающие произведения от несанкционированного использования     |
| Свободная лицензия    | Условие использования произведения, разрешающее его распространение               |
| Цифровой след         | Совокупность данных, оставляемых пользователем в сети                             |
| Чек-лист безопасности | Перечень критериев для проверки контента на соответствие требованиям безопасности |

## 9\. Вопросы для самопроверки
