## 1\. Облачные технологии: понятие и модели

### 1\.1. Что такое облачные технологии

До появления облачных технологий пользователь хранил файлы на жёстком диске своего компьютера, а программы устанавливал с диска или загружал из Интернета. Если компьютер ломался, данные могли быть потеряны. Если нужно было поработать с другого устройства -- файл приходилось переносить на флешке или пересылать по почте.

**Облачные технологии** решили эти проблемы.

<note type="quote">
  **Определение.** **Облачные технологии** -- модель предоставления вычислительных ресурсов (дискового пространства, процессорного времени, программного обеспечения) через сеть Интернет по запросу пользователя. Пользователь получает доступ к ресурсам удалённых серверов, не заботясь об их физическом расположении и обслуживании.
</note>

Название «облако» -- метафора: на схемах компьютерных сетей Интернет традиционно изображается в виде облака. Пользователю не важно, где физически находятся серверы -- в Москве, Новосибирске или другой стране. Он просто загружает и скачивает данные через браузер или приложение.

### 1\.2. Три модели облачных сервисов

Облачные сервисы различаются по тому, **что именно** предоставляется пользователю:

| Модель | Английское название | Что предоставляется | Примеры | Кому нужно |
|---|---|---|---|---|
| **Инфраструктура как сервис** | IaaS (Infrastructure as a Service) | Виртуальные серверы, дисковое пространство, сетевые ресурсы | Виртуальные серверы для хостинга сайтов, облачные платформы для разработчиков | Компании, разработчики |
| **Платформа как сервис** | PaaS (Platform as a Service) | Готовая среда для разработки и запуска приложений | Платформы для создания и тестирования программ без управления серверами | Программисты, команды разработки |
| **Программное обеспечение как сервис** | SaaS (Software as a Service) | Готовые приложения, доступные через браузер | Онлайн-офисы, облачные хранилища, электронная почта, мессенджеры | Все пользователи |

В повседневной жизни и в учёбе вы чаще всего сталкиваетесь с моделью **SaaS**: открываете браузер и пользуетесь готовым приложением, не устанавливая его на компьютер.

### 1\.3. Преимущества и ограничения облачных технологий

**Преимущества:**

| Преимущество | Пояснение |
|---|---|
| Доступность из любой точки мира | Достаточно браузера и Интернета |
| Работа с любого устройства | Компьютер, планшет, смартфон |
| Автоматическое обновление | Провайдер обновляет ПО без участия пользователя |
| Надёжность хранения | Данные хранятся на серверах с резервным копированием |
| Совместная работа | Несколько пользователей могут работать с одними данными одновременно |
| Масштабируемость | Объём ресурсов можно увеличить по мере необходимости |
| Отсутствие затрат на оборудование | Не нужно покупать серверы и лицензии на ПО |

**Ограничения:**

| Ограничение | Пояснение |
|---|---|
| Зависимость от Интернета | Без подключения к сети доступ к облаку невозможен |
| Ограниченная функциональность | Онлайн-версии программ могут уступать настольным по возможностям |
| Зависимость от провайдера | Если сервис прекратит работу, данные могут стать недоступны |
| Вопросы конфиденциальности | Данные хранятся на чужих серверах |

## 2\. Облачные хранилища данных

### 2\.1. Назначение и принцип работы

<note type="quote">
  **Определение.** **Облачное хранилище** -- интернет-сервис, предоставляющий пользователю дисковое пространство на удалённых серверах для хранения файлов и доступа к ним с любого устройства через Интернет.
</note>

**Принцип работы:**

1. Пользователь загружает файл через браузер или приложение.
2. Файл передаётся по защищённому соединению на сервер провайдера.
3. Сервер сохраняет файл (часто в нескольких копиях на разных физических носителях).
4. Пользователь может скачать, просмотреть, изменить или удалить файл с любого устройства, авторизовавшись в аккаунте.

### 2\.2. Основные функции облачных хранилищ

| Функция | Описание |
|---|---|
| **Хранение файлов** | Документы, фото, видео, музыка, архивы |
| **Синхронизация** | Автоматическое обновление файлов на всех подключённых устройствах |
| **Совместный доступ** | Предоставление ссылки на файл или папку другим пользователям |
| **Резервное копирование** | Защита данных при поломке или потере устройства |
| **Версионность** | Сохранение предыдущих версий файла с возможностью восстановления |
| **Автономный доступ** | Возможность отметить файлы для работы без Интернета |

### 2\.3. Примеры облачных хранилищ

| Сервис | Особенности |
|---|---|
| Яндекс Диск | Интеграция с Яндекс Документами, 10 ГБ бесплатно |
| Облако Mail | Интеграция с почтой, 8 ГБ бесплатно |
| Google Drive | Тесная интеграция с Google Документами, 15 ГБ бесплатно |
| Microsoft OneDrive | Интеграция с Microsoft 365, 5 ГБ бесплатно |
| Dropbox | Простой интерфейс, 2 ГБ бесплатно |

### 2\.4. Использование в учёбе

- Хранение конспектов, презентаций, рефератов.
- Передача выполненных работ учителю через ссылку.
- Общая папка группы для обмена файлами при подготовке проекта.
- Резервное копирование важных документов.

## 3\. Онлайн-офис: понятие, состав, возможности

### 3\.1. Определение

<note type="quote">
  **Определение.** **Онлайн-офис** -- веб-приложение (модель SaaS), позволяющее создавать, редактировать и форматировать документы непосредственно в браузере, без установки программного обеспечения на компьютер.
</note>

Онлайн-офис является одним из наиболее ярких примеров модели SaaS: приложение работает на сервере провайдера, а пользователь взаимодействует с ним через браузер.

### 3\.2. Состав онлайн-офиса

Типичный онлайн-офис включает несколько компонентов:

| Компонент | Назначение | Аналог настольного ПО |
|---|---|---|
| **Текстовый редактор** | Создание и форматирование текстовых документов | Текстовый процессор |
| **Электронные таблицы** | Вычисления, анализ данных, построение диаграмм | Программа для работы с таблицами |
| **Редактор презентаций** | Создание слайдов с текстом, изображениями, анимацией | Программа для создания презентаций |
| **Графический редактор** (не всегда) | Создание схем, диаграмм, простых рисунков | Программа для рисования |
| **Формы** (не всегда) | Создание опросов и анкет | -- |

### 3\.3. Примеры онлайн-офисов

| Онлайн-офис | Текстовый редактор | Таблицы | Презентации |
|---|---|---|---|
| Яндекс Документы | Яндекс Документы | Яндекс Таблицы | Яндекс Презентации |
| МойОфис | МойОфис Документы | МойОфис Таблицы | МойОфис Презентации |
| Google Workspace | Google Docs | Google Sheets | Google Slides |
| Microsoft 365 Online | Word Online | Excel Online | PowerPoint Online |
| Р7-Офис | Р7-Офис Документы | Р7-Офис Таблицы | Р7-Офис Презентации |

### 3\.4. Ключевые возможности онлайн-офиса

| Возможность | Описание |
|---|---|
| **Создание и редактирование** | Набор текста, вставка объектов, форматирование |
| **Стилевое форматирование** | Применение стилей заголовков, основного текста |
| **Автосохранение** | Документ сохраняется автоматически при каждом изменении |
| **Совместная работа** | Несколько пользователей редактируют одновременно |
| **История версий** | Просмотр и восстановление предыдущих версий |
| **Комментарии** | Замечания к фрагментам текста без изменения самого текста |
| **Совместный доступ** | Настройка прав: просмотр, комментирование, редактирование |
| **Работа в любом браузере** | Не зависит от операционной системы |
| **Экспорт** | Скачивание в форматах .docx, .pdf, .odt и др. |

## 4\. Основные приёмы работы в онлайн-офисе

### 4\.1. Интерфейс текстового редактора

Интерфейс онлайн-редактора схож с настольным текстовым процессором:

```
┌─────────────────────────────────────────────────────┐
│  Меню: Файл | Правка | Вставка | Формат | ...      │
├─────────────────────────────────────────────────────┤
│  Панель инструментов:                               │
│  [Шрифт] [Размер] [Ж] [К] [Ч] | [Выравнивание]    │
│  [Списки] [Отступы] | [Вставка таблицы/картинки]   │
├─────────────────────────────────────────────────────┤
│                                                     │
│                    Область                          │
│                  документа                          │
│                                                     │
│                                                     │
│                                                     │
├─────────────────────────────────────────────────────┤
│  Строка состояния: страниц, слов, символов         │
└─────────────────────────────────────────────────────┘
```

### 4\.2. Создание документа

1. Открыть сервис онлайн-офиса в браузере.
2. Нажать кнопку **«Создать»** (или «+»).
3. Выбрать тип документа: «Документ», «Таблица» или «Презентация».
4. Переименовать документ (обычно клик по названию в верхней части окна).

### 4\.3. Форматирование текста

**Свойства символов:**

- Шрифт (гарнитура): рубленые, с засечками, моноширинные.
- Размер шрифта (в пунктах): для основного текста обычно 12–14 пт.
- Начертание: **полужирное**, *курсив*, <u>подчёркнутое</u>.
- Цвет текста.

**Свойства абзацев:**

- Выравнивание: по левому краю, по центру, по правому краю, по ширине.
- Абзацный отступ (красная строка).
- Межстрочный интервал.
- Отступы слева и справа.

**Стили форматирования:**

- «Заголовок 1» -- для главного заголовка документа.
- «Заголовок 2» -- для подзаголовков разделов.
- «Обычный» (основной текст) -- для основного содержания.

<note type="quote">
  **Совет.** Использование стилей вместо ручного форматирования обеспечивает единообразие документа и позволяет автоматически формировать оглавление.
</note>

### 4\.4. Структурирование документа

**Списки:**

- **Маркированный список** -- для перечисления элементов без определённого порядка.
- **Нумерованный список** -- для последовательности шагов или ранжирования.
- **Многоуровневый список** -- для иерархической структуры.

**Таблицы:**

- Вставка через меню «Вставка» -> «Таблица».
- Выбор количества строк и столбцов.
- Заполнение ячеек, объединение, форматирование границ.

**Изображения и ссылки:**

- Вставка изображения из файла или по ссылке.
- Настройка обтекания текстом.
- Создание гиперссылок на внешние ресурсы.

### 4\.5. Сохранение и экспорт

| Действие | Как выполняется |
|---|---|
| Автосохранение | Происходит автоматически, вручную сохранять не нужно |
| Экспорт в файл | Меню «Файл» -> «Скачать как…» -> выбор формата (.docx, .pdf, .odt) |
| Печать | Меню «Файл» -> «Печать» |
| Копия в облако | Документ по умолчанию хранится в облачном хранилище аккаунта |

## 5\. Совместная работа в онлайн-офисе

### 5\.1. Настройка совместного доступа

Для организации совместной работы необходимо предоставить доступ другим пользователям:

**Способы предоставления доступа:**

| Способ | Описание | Когда использовать |
|---|---|---|
| По электронной почте | Указать email пользователя, выбрать уровень прав | Для конкретных людей |
| По ссылке | Сгенерировать ссылку, настроить права | Для группы, когда не знаете всех email |

**Уровни прав доступа:**

| Уровень | Что может делать пользователь |
|---|---|
| **Только просмотр** | Читать документ, не изменяя его |
| **Комментирование** | Читать и оставлять комментарии, не редактируя текст |
| **Редактирование** | Полноценно изменять содержимое документа |

### 5\.2. Одновременное редактирование

При совместной работе в онлайн-офисе:

- Каждый пользователь видит **курсоры** других участников (обычно разного цвета).
- Изменения отображаются **в реальном времени**.
- Можно работать в **разных частях** документа одновременно.
- Система **автоматически объединяет** изменения без конфликтов.

**Рекомендации для эффективной совместной работы:**

1. Заранее распределите разделы: кто какую часть пишет.
2. Работайте в разных частях документа, чтобы не мешать друг другу.
3. Используйте комментарии для обсуждения, а не удаляйте чужой текст без согласования.
4. Периодически проверяйте историю версий.

### 5\.3. Использование комментариев

**Комментарий** -- это заметка, привязанная к фрагменту текста, которая не изменяет сам документ.

**Как использовать:**

1. Выделите фрагмент текста.
2. Нажмите «Добавить комментарий» (или значок 💬).
3. Введите текст комментария.
4. Отправьте.

Комментарии удобны для:

- вопросов автору («Что ты имеешь в виду?»);
- предложений по улучшению («Может, добавить пример?»);
- отметок о необходимости исправления;
- обсуждения без изменения основного текста.

## 6\. История версий и восстановление

### 6\.1. Что такое история версий

<note type="quote">
  **Определение.** **История версий** -- функция онлайн-офиса, автоматически сохраняющая «снимки» документа в различные моменты времени и позволяющая просмотреть, кто и какие изменения вносил, а при необходимости -- вернуться к предыдущей версии.
</note>

### 6\.2. Возможности истории версий

| Функция | Описание |
|---|---|
| Просмотр версий | Открыть документ в том виде, в котором он был в определённый момент |
| Авторство изменений | Увидеть, кто именно внёс конкретные правки |
| Восстановление | Вернуть документ к предыдущей версии |
| Именование версий | Дать версии понятное название (например, «После проверки учителем») |

### 6\.3. Как использовать историю версий

1. Меню «Файл» -> «История версий» (или «История изменений»).
2. В правой панели отображается список версий с датами и именами авторов.
3. Кликните на версию, чтобы просмотреть документ в том состоянии.
4. При необходимости нажмите «Восстановить эту версию».

<note type="quote">
  **Важно.** История версий -- это ваша «страховка». Если кто-то случайно удалил важный фрагмент или форматирование «поехало», вы всегда можете вернуться к рабочей версии.
</note>

## 7\. Безопасность при работе с облачными сервисами

### 7\.1. Защита аккаунта

| Правило | Пояснение |
|---|---|
| Надёжный пароль | Не менее 12 символов, буквы разного регистра, цифры, спецсимволы |
| Уникальность пароля | Не используйте один пароль для облака и других сервисов |
| Двухфакторная аутентификация | Включите 2ФА для защиты от несанкционированного входа |
| Проверка сессий | Регулярно просматривайте список устройств с доступом к аккаунту |
| Выход на чужих устройствах | Всегда выходите из аккаунта после работы на чужом компьютере |

### 7\.2. Защита документов

| Правило | Пояснение |
|---|---|
| Проверяйте настройки доступа | Перед тем как делиться ссылкой, убедитесь, что права установлены корректно |
| Не публикуйте личные данные | Не размещайте в документах пароли, паспортные данные, адреса |
| Ограничивайте доступ по времени | Если доступ нужен временно, отзовите его после завершения работы |
| Используйте закрытые ссылки | Не размещайте ссылки на документы в открытых чатах и соцсетях |

### 7\.3. Защита при совместной работе

- Предоставляйте право **редактирования** только тем, кто действительно работает над документом.
- Для учителя или проверяющего достаточно права **«только просмотр»** или **«комментирование»**.
- Не передавайте пароли от аккаунта другим участникам группы.
- При завершении проекта закройте доступ для тех, кому он больше не нужен.

## 8\. Сравнение локального и облачного подходов

### 8\.1. Сравнительная таблица

| Критерий | Локальная программа (на компьютере) | Онлайн-офис (в браузере) |
|---|---|---|
| Установка | Требует установки | Не нужна, достаточно браузера |
| Интернет | Не нужен (после установки) | Необходим для работы |
| Совместная работа | Пересылка файлов, конфликт версий | Одновременное редактирование |
| Сохранение | Ручное или автоматическое в файл | Автоматическое в облако |
| История версий | Ограничена (автосохранение) | Полная, с авторством |
| Доступность | Только на данном устройстве | С любого устройства |
| Функциональность | Обычно шире (макросы, сложные шаблоны) | Базовый набор функций |
| Зависимость от сервера | Нет | Да |
| Обновления | Пользователь устанавливает вручную или автоматически | Обновляет провайдер |

### 8\.2. Когда что использовать

| Ситуация | Оптимальный выбор |
|---|---|
| Групповой проект, работа из разных мест | Онлайн-офис |
| Сложный документ с макросами, нестандартным форматированием | Локальная программа |
| Работа без доступа к Интернету | Локальная программа |
| Быстрое создание и совместное редактирование | Онлайн-офис |
| Долгосрочный архив документов | Локальное хранение + резервная копия в облаке |
| Оперативный обмен файлами | Облачное хранилище |

### 8\.3. Комбинированный подход

На практике часто используется **комбинация** обоих подходов:

- Основной рабочий документ создаётся и редактируется в онлайн-офисе.
- Итоговая версия скачивается в формате .docx или .pdf.
- Резервная копия сохраняется в облачном хранилище.
- При необходимости сложного форматирования файл открывается в локальной программе.

## 9\. Ключевые термины урока

| Термин | Определение |
|---|---|
| Облачные технологии | Модель предоставления вычислительных ресурсов через Интернет по запросу |
| IaaS | Инфраструктура как сервис: виртуальные серверы и хранилища |
| PaaS | Платформа как сервис: среда для разработки приложений |
| SaaS | Программное обеспечение как сервис: готовые приложения в браузере |
| Облачное хранилище | Онлайн-сервис для хранения файлов на удалённых серверах |
| Синхронизация | Автоматическое обновление данных на всех устройствах пользователя |
| Онлайн-офис | Веб-приложение для создания и редактирования документов в браузере |
| Автосохранение | Автоматическое сохранение документа при каждом изменении |
| Совместный доступ | Предоставление прав на просмотр, комментирование или редактирование другим пользователям |
| История версий | Автоматически сохраняемые «снимки» документа с возможностью восстановления |
| Комментарий | Заметка к фрагменту текста, не изменяющая сам документ |
| Версионность | Сохранение предыдущих версий файла |
| Резервное копирование | Создание запасных копий данных для защиты от потери |
