## 1\. Главное о теме

Почти любая обработка массива сводится к одному проходу с накопителем: суммой, максимумом, счётчиком или найденным индексом. Четыре шаблона закрывают большинство задач, а верный выбор начального значения накопителя решает, будет ли ответ правильным.

Дальше разберём по шагам: общая схема: проход и накопитель; сумма и среднее значение; минимум и максимум; подсчёт элементов по условию; линейный поиск.

---

## 2\. Общая схема: проход и накопитель

> **Определение.** Накопитель — переменная, в которой по шагам собирается результат обработки массива: сумма, произведение, максимум, количество или найденный индекс.

Любой типовой алгоритм обработки массива устроен одинаково: перед циклом заводят переменную-накопитель, внутри цикла её обновляют, после цикла печатают. Различаются алгоритмы только начальным значением накопителя и тем, как он обновляется. Освоив эту схему, вы перестаёте писать решение «с нуля» и начинаете узнавать в условии знакомый шаблон.

Число проходов тоже важно. Если задача требует и суммы, и максимума, и количества, все три величины считают в одном цикле: лишние проходы увеличивают время работы, а на массиве в миллион элементов это заметно.

| Что ищем | Начальное значение | Обновление в цикле |
|:---|:---|:---|
| сумма | 0 | s += x |
| произведение | 1 | p *= x |
| максимум | a[0] | if x > m: m = x |
| количество по условию | 0 | if условие: c += 1 |
| признак «есть такое» | False | if условие: f = True |

> Начальное значение — не формальность. Сумма начинается с нуля, потому что ноль не меняет результат сложения; произведение — с единицы; а максимум нельзя начинать с нуля, если числа могут быть отрицательными.

```text
накопитель = начальное значение
for x in a:
    обновить накопитель
print(накопитель)
```

## 3\. Сумма и среднее значение

Сумма — самый простой шаблон: заводим s = 0, в цикле прибавляем каждый элемент, после цикла печатаем. Среднее арифметическое получают делением суммы на количество элементов, то есть на len(a). Если массив пуст, делить не на что: программа завершится ошибкой деления на ноль, поэтому в общем случае длину проверяют.

Программа выведет 60 и 12.0: сумма 10 + 4 + 22 + 8 + 16 равна 60, элементов пять, среднее 60 / 5 = 12. Обратите внимание на точку в записи 12.0 — результат деления в Python всегда вещественный, даже если делится нацело.

В Python есть готовые функции sum(a), max(a), min(a) и len(a) — ими пользуются в реальных программах. Но на контрольной и на экзамене требуется написать цикл, поэтому шаблон нужно уметь воспроизводить руками, а готовые функции использовать для проверки своего ответа.

> Если нужен целый результат, используют целочисленное деление s // len(a), а если нужна точность до сотых — округление round(s / len(a), 2). Средний балл обычно округляют до десятых.

```python
a = [10, 4, 22, 8, 16]
s = 0
for x in a:
    s += x
print(s, s / len(a))
```

## 4\. Минимум и максимум

> **Определение.** Минимум (максимум) массива — элемент, значение которого не больше (не меньше) значений всех остальных элементов.

Максимум ищут так: за начальное значение берут первый элемент, затем каждый следующий сравнивают с текущим максимумом и при необходимости заменяют его. Начинать с нуля нельзя: в массиве [-5, -12, -3] все числа меньше нуля, и «максимум» оказался бы нулём — числом, которого в массиве нет.

Здесь вместе со значением запоминается индекс: переменная imax хранит номер ячейки, где встретился текущий максимум. Программа выведет 9 2. Поиск минимума отличается только знаком в условии: if a[i] < mn.

Отдельная тонкость — пустой массив. Обращение a[0] к пустому списку даёт IndexError, поэтому поиск максимума имеет смысл только для непустого массива, и в условии задач длина обычно задана больше нуля.

> Если условие записать строгим (a[i] > mx), при нескольких одинаковых максимумах сохранится первый из них. Нестрогое условие (a[i] >= mx) сохранит последний. В задаче об этом стоит подумать заранее.

```python
a = [7, 2, 9, 4]
mx = a[0]
imax = 0
for i in range(len(a)):
    if a[i] > mx:
        mx = a[i]
        imax = i
print(mx, imax)
```

## 5\. Подсчёт элементов по условию

Подсчёт по условию — это цикл, в котором проверяется условие, а накопитель увеличивается на единицу только при его выполнении. Тот же цикл позволяет одновременно накапливать сумму подходящих элементов: например, посчитать количество положительных чисел и их сумму. Это экономнее, чем проходить массив дважды.

Положительных элементов три — 4, 7 и 9, их сумма 20, среднее 20 / 3 ≈ 6,67. На экран выводится 3 20 6.67. Ноль не считается положительным числом, поэтому он не попал ни в счётчик, ни в сумму.

Условие может быть составным. Например, «числа, оканчивающиеся на 5 и большие 20» записывают так: if x % 10 == 5 and x > 20. Составное условие проверяется полностью на каждом шаге, поэтому его стоит продумать до написания цикла.

> Среднее по условию делят на счётчик cnt, а не на длину массива len(a). Для нашего примера правильный ответ 6,67, а деление на 6 дало бы 3,33 — типичная ошибка на контрольных работах.

```python
a = [4, -2, 0, 7, -1, 9]
cnt = 0
s = 0
for x in a:
    if x > 0:
        cnt += 1
        s += x
print(cnt, s, round(s / cnt, 2))
```

## 6\. Линейный поиск

> **Определение.** Линейный (последовательный) поиск — перебор элементов массива по порядку до первого совпадения с искомым значением.

Линейный поиск — это перебор элементов до совпадения с искомым значением. Если элемент найден, запоминают его индекс; если после полного перебора индекс так и не изменился, значит, элемента в массиве нет. Начальное значение −1 удобно именно потому, что такого индекса не существует: его невозможно спутать с настоящей позицией.

Для значения 21 сравнения идут по шагам: a[0] = 4 не подходит, a[1] = 9 не подходит, a[2] = 14 не подходит, a[3] = 21 совпало — запоминаем pos = 3 и выходим из цикла командой break. На экран выводится 3.

Время поиска зависит от расположения элемента: в лучшем случае одно сравнение, в худшем — столько, сколько элементов в массиве. Для тысячи элементов худший случай требует тысячи сравнений, поэтому для больших упорядоченных массивов применяют другие алгоритмы, с которыми познакомятся позже.

> Если элемент встречается несколько раз, линейный поиск с break находит первый из них. Если нужно найти последний, break убирают: тогда цикл пройдёт целиком и pos сохранит номер последнего совпадения.

```python
a = [4, 9, 14, 21, 30]
key = 21
pos = -1
for i in range(len(a)):
    if a[i] == key:
        pos = i
        break
print(pos)
```

## 7\. Разобранные примеры

### Пример 1. Сумма и среднее за один проход

**Условие.** Дан массив a = [12, 7, 25, 3, 18]. Найти сумму и среднее арифметическое его элементов.

**Решение.** Заводим накопитель s = 0 и проходим массив циклом. По шагам: s = 12, затем s = 19, затем s = 44, затем s = 47, затем s = 65. Длина массива пять, поэтому среднее равно 65 / 5 = 13.0. Проверка готовыми функциями: sum([12, 7, 25, 3, 18]) тоже даёт 65, len() даёт 5.

**Ответ:** сумма 65, среднее 13.0.

### Пример 2. Максимум в массиве отрицательных чисел

**Условие.** Найти максимум и минимум массива a = [-5, -12, -3, -8], если поиск начинается с нуля, и если он начинается с первого элемента.

**Решение.** При начальном значении 0 ни одно число не окажется больше нуля, поэтому «максимум» останется равным 0 — числа, которого в массиве нет. При начальном значении a[0] = −5 сравнения дают: −12 не больше −5, значит, максимум не меняется; −3 больше −5, максимум становится −3; −8 не больше −3. Итог −3. Для минимума начинаем с −5 и получаем −12. Сумма элементов равна −28.

**Ответ:** максимум −3, минимум −12; при инициализации нулём максимум был бы найден неверно.

### Пример 3. Подсчёт и поиск в одном массиве

**Условие.** Дан массив a = [4, 9, 14, 21, 30]. Найти первое число, кратное 7, его индекс, число выполненных сравнений, а также количество элементов, больших 10.

**Решение.** Кратность проверяем остатком от деления: if a[i] % 7 == 0. Сравнения идут по порядку: 4 не кратно, 9 не кратно, 14 кратно — найдено на третьем сравнении, индекс 2. Подсчёт «больше 10» можно вести в том же цикле отдельным счётчиком: 4 и 9 не подходят, 14, 21 и 30 подходят, счётчик равен 3. Если писать поиск и подсчёт двумя циклами, работа удвоится без пользы.

**Ответ:** первое кратное 7 — это 14 с индексом 2, потребовалось 3 сравнения; элементов больше 10 три.

## 10\. Итоги урока

На этом уроке вы узнали:
