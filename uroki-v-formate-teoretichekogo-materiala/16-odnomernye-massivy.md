## 1\. Главное о теме

Массив — это одна переменная со многими ячейками, и вся его сила в том, что номер ячейки можно вычислить циклом. Понять индекс, длину и границы — значит заменить тридцать переменных одним списком и перестать получать IndexError.

Дальше разберём по шагам: тридцать переменных или один массив; индекс и длина: почему нумерация с нуля; как создать список; ввод и вывод массива; пять типичных ошибок при работе с массивом.

## 2\. Тридцать переменных или один массив

> **Определение.** Массив — набор элементов одного типа, упорядоченных по индексам, каждый из которых доступен по своему номеру.

Переменная хранит одно значение: одно число, одну строку. Но в задачах данные почти всегда идут набором: рост всех учеников класса, цены товаров в чеке, оценки за контрольную. Заводить отдельную переменную на каждое значение неудобно: имена путаются, а обработать тридцать переменных циклом невозможно — цикл умеет работать с номерами, а не с именами.

Массив (в русской школьной традиции — одномерный массив) хранит много значений под одним именем, а место каждого значения определяется номером. Если массив называется a, то его элементы — это a[0], a[1], a[2] и так далее. Номер в квадратных скобках и есть индекс.

Отдельная выгода массива — единообразие обработки. Сумма, максимум, подсчёт по условию выполняются одним и тем же циклом, меняется только тело. Именно поэтому массивы изучают вместе с типовыми алгоритмами обработки.

| Что делаем | Без массива | С массивом |
|:---|:---|:---|
| храним 30 температур | 30 переменных t1 … t30 | одна переменная a из 30 ячеек |
| вводим данные | 30 строк input() | один цикл на 30 шагов |
| находим сумму | сумма тридцати слагаемых | цикл из четырёх строк |
| меняем число дней | переписываем программу | меняем одно число |

> В Python массив реализован типом list и называется списком. Слово «массив» в учебниках и слово list в программе обозначают одно и то же: упорядоченный набор элементов с доступом по номеру.

## 3\. Индекс и длина: почему нумерация с нуля

> **Определение.** Индекс — номер элемента в массиве; в Python нумерация начинается с нуля, поэтому у массива из n элементов индексы идут от 0 до n − 1.

> **Определение.** Длина массива — количество хранящихся в нём элементов; в Python её возвращает функция len().

В математике элементы последовательности нумеруют с единицы, а в программировании — с нуля. Причина в адресации: индекс показывает, на сколько позиций нужно сдвинуться от начала массива, а первый элемент стоит в самом начале, то есть со сдвигом ноль. Поэтому у списка из пяти элементов допустимы индексы 0, 1, 2, 3, 4, а индекса 5 не существует.

Программа выведет 8, 6, 10 и 5. Запись a[-1] означает последний элемент: отрицательный индекс отсчитывается от конца массива, поэтому a[-1] — это a[4]. Функция len(a) возвращает количество элементов, а их пять.

Зная длину, легко записать безопасный перебор всех элементов: `for i in range(len(a)):` даёт ровно допустимые индексы. Запись `for i in range(len(a) + 1):` даёт на один шаг больше и обязательно закончится ошибкой.

| Длина массива | Допустимые индексы | Последний индекс |
|:---|:---|:---|
| 1 | 0 | 0 |
| 5 | 0 … 4 | 4 |
| 10 | 0 … 9 | 9 |
| 30 | 0 … 29 | 29 |

> Самая частая ошибка новичка — считать, что последний индекс равен len(a). Он равен len(a) − 1. Обращение a[len(a)] всегда означает выход за границу и вызывает ошибку IndexError: list index out of range.

```python
a = [8, 3, 15, 6, 10]
print(a[0])
print(a[3])
print(a[-1])
print(len(a))
```

## 4\. Как создать список

Самый простой способ — перечислить значения в квадратных скобках через запятую: `a = [4, 7, 0, 5]`. Так задают массив, когда значения известны заранее, например оценки за четыре задания. Если значения нужно вычислить или ввести, список создают «заготовкой» и заполняют в цикле.

Здесь использованы четыре приёма. b — пять нулей, полученных умножением списка из одного элемента. c — числа от 1 до 5: range(1, 6) перечисляет 1, 2, 3, 4, 5, а list() превращает результат в список. d начинается пустым и пополняется методом append. На экран выведется: [4, 7, 0, 5] [0, 0, 0, 0, 0] [1, 2, 3, 4, 5] [0, 1, 4].

| Запись | Что получается | Когда применяют |
|:---|:---|:---|
| [4, 7, 0, 5] | четыре заданных числа | значения известны заранее |
| [0] * 5 | [0, 0, 0, 0, 0] | нужна заготовка нужной длины |
| list(range(1, 6)) | [1, 2, 3, 4, 5] | нужны подряд идущие числа |
| [] и append(x) | растущий список | длина заранее неизвестна |

> Умножение работает только со списком-заготовкой: [0] * 5 даёт пять нулей, [0] * 0 — пустой список. Но если элементами были бы вложенные списки, копия оказалась бы общей — для одномерного массива из чисел такой опасности нет.

```python
a = [4, 7, 0, 5]
b = [0] * 5
c = list(range(1, 6))
d = []
for i in range(3):
    d.append(i * i)
print(a, b, c, d)
```

## 5\. Ввод и вывод массива

В задачах массив обычно задают одной строкой: «5 12 7 30». Метод split() разрезает строку по пробелам и возвращает набор строк, а int() превращает каждую часть в число. Всю операцию записывают одной строкой: `a = [int(x) for x in input().split()]` — это включение, то есть создание списка по образцу.

Если ввести 5 12 7, программа выведет 3 24, а затем напечатает 5 12 7 в одну строку: параметр end=' ' отменяет перевод строки после каждого числа. Функции sum(a) и len(a) — готовые инструменты Python, но на уроке мы будем писать и свои циклы, чтобы понимать, как они устроены.

Такой перебор печатает пары «индекс и значение»: 0 8, затем 1 3, 2 15 и 3 6. Если номер не нужен, пишут короче: `for x in a: print(x)` — тогда цикл идёт по значениям, а не по индексам.

> Если написать print(a), на экран попадёт весь список вместе с квадратными скобками и запятыми: [8, 3, 15, 6]. Для ответа задачи обычно нужен вывод без скобок, поэтому используют print(*a) или цикл.

```python
s = input()
a = [int(x) for x in s.split()]
print(len(a), sum(a))
for x in a:
    print(x, end=' ')
```

```python
a = [8, 3, 15, 6]
for i in range(len(a)):
    print(i, a[i])
```

## 6\. Пять типичных ошибок при работе с массивом

Первая и самая частая ошибка — выход за границу. Программа `a = [8, 3, 15]` и затем `print(a[3])` завершится сообщением IndexError: list index out of range, потому что допустимы только индексы 0, 1 и 2. Сообщение об ошибке полезно читать целиком: в нём указаны и номер строки, и вид ошибки.

Вторая ошибка — забыть преобразование типов. Если записать `a = input().split()`, массив будет состоять из строк, и сравнение `a[0] < 10` даст неверный результат: строка '9' больше строки '10', потому что символ 9 идёт позже символа 1. Третья ошибка — пустой ввод: если пользователь нажал Enter, split() вернёт пустой список, и обращение a[0] сразу даст IndexError.

| Ошибка в программе | Что произойдёт | Как исправить |
|:---|:---|:---|
| a[3] при длине 3 | IndexError | использовать a[2] или len(a) − 1 |
| range(len(a) + 1) | IndexError на последнем шаге | range(len(a)) |
| a = input().split() | элементы-строки, неверные сравнения | [int(x) for x in a] |
| b = a, затем b[0] = 0 | изменился и a | b = a[:] или b = list(a) |
| sum(a) / len(a) при пустом a | деление на ноль | проверить len(a) > 0 |

> Присваивание b = a не создаёт новый массив: обе переменные указывают на один и тот же список, поэтому изменение b[0] меняет и a[0]. Настоящая копия — это b = a[:] или b = list(a).

```python
a = [8, 3, 15]
print(a[3])
```

## 7\. Разобранные примеры

### Пример 1. Чтение элементов по индексу

**Условие.** Дан список a = [8, 3, 15, 6, 10]. Что выведут команды `print(a[1], a[-1], len(a))` и `print(a[0] + a[3])`? Что произойдёт при обращении a[5]?

**Решение.** Индексы идут с нуля, поэтому a[1] — второй элемент, это 3. Отрицательный индекс −1 указывает на последний элемент, то есть на 10. Длина списка — 5 элементов. Во второй команде складываются первый и четвёртый элементы: 8 + 6 = 14. Обращение a[5] выходит за границу: допустимые индексы 0 … 4, поэтому программа завершится ошибкой IndexError.

**Ответ:** будут выведены строки «3 10 5» и «14»; обращение a[5] вызывает IndexError: list index out of range.

### Пример 2. Создание списка по правилу

**Условие.** Создать список из шести чисел, где элемент с индексом i равен (i + 1)², и найти сумму его элементов.

**Решение.** Сначала делаем заготовку нужной длины: `b = [0] * 6`. Затем цикл `for i in range(6):` заполняет ячейки: при i = 0 получаем 1, при i = 1 — 4, при i = 2 — 9, при i = 3 — 16, при i = 4 — 25, при i = 5 — 36. Список имеет вид [1, 4, 9, 16, 25, 36]. Сумма считается циклом по значениям: 1 + 4 + 9 + 16 + 25 + 36 = 91.

**Ответ:** [1, 4, 9, 16, 25, 36], сумма равна 91.

### Пример 3. Вывод массива в обратном порядке

**Условие.** Ввести семь чисел и вывести их в обратном порядке. Проверить работу на данных 4 8 15 16 23 42 7.

**Решение.** Ввод оформляем одной строкой: `a = [int(x) for x in input().split()]`. Длина массива 7, значит, последний индекс равен 6. Обратный перебор начинается с индекса len(a) − 1 и идёт до нуля включительно, поэтому в range() указывают три аргумента: `for i in range(len(a) - 1, -1, -1): print(a[i])`. Шаги: i = 6 даёт 7, i = 5 даёт 42, i = 4 даёт 23, i = 3 даёт 16, i = 2 даёт 15, i = 1 даёт 8, i = 0 даёт 4.

**Ответ:** 7 42 23 16 15 8 4.
