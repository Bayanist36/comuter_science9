Поток и массив: две модели работы с данными

Поток данных — последовательность значений, которые поступают по одному, обрабатываются сразу и не сохраняются целиком.
  • Массив хранит все значения, поток — только текущее
  • Длина потока часто неизвестна заранее
  • Память: n ячеек против нескольких переменных
  • Проход по потоку возможен только один

Тезис: Поток и массив: две модели работы с данными: Поток данных

  • последовательность значений, которые поступают по одному, обрабатываются сразу и не сохраняются целиком.
  • Когда все числа уже лежат в массиве, можно пройти по ним сколько угодно раз: сначала найти сумму, потом минимум, потом посчитать чётные. У потока такого преимущества…
  • Массив хранит все значения, поток — только текущее
  • Длина потока часто неизвестна заранее
