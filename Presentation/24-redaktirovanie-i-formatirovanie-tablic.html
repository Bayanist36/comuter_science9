Значение и его представление

Числовой формат — правило отображения значения в ячейке: число знаков после запятой, разделитель разрядов, знак валюты, вид записи даты.
  • В ячейке хранится значение, на экране — его формат
  • Формат не округляет число, а только показывает его
  • «####» — признак узкого столбца, а не ошибки
  • Формат выбирают по смыслу данных, а не по вкусу

Тезис: Значение и его представление: Числовой формат

  • правило отображения значения в ячейке: число знаков после запятой, разделитель разрядов, знак валюты, вид записи даты.
  • У каждой ячейки есть содержимое и оформление. Содержимое — то, что действительно хранится: число 1234,567, дата, текст или формула. Оформление — шрифт, цвет, границы,…
  • В ячейке хранится значение, на экране — его формат
  • Формат не округляет число, а только показывает его

Объединение ячеек

Объединённая ячейка — ячейка, образованная из нескольких соседних ячеек, которая ведёт себя как одна и хранит только одно значение.
  • Объединение нужно для заголовков, а не для данных
  • Значение хранится только в левой верхней ячейке
  • Адрес у объединённой ячейки — тоже левый верхний
  • Сортировка по объединённому диапазону не работает

Тезис: Объединение ячеек: Объединённая ячейка

  • ячейка, образованная из нескольких соседних ячеек, которая ведёт себя как одна и хранит только одно значение.
  • Объединение собирает несколько соседних ячеек в одну. Оно нужно там, где надпись должна стоять над всей таблицей: заголовок «Ведомость за четверть» пишут в A1, выделяют…
  • Объединение нужно для заголовков, а не для данных
  • Значение хранится только в левой верхней ячейке

Границы, заливка и выравнивание

Сетка, которую видно на экране, — это разметка листа, а не оформление. На бумагу она не выводится: если не задать границы, таблица напечатается без…

  • Сетка на экране не печатается

  • Заливка выделяет блок, но не заменяет фильтр
  • Перенос по словам спасает узкие столбцы

Условное форматирование

Условное форматирование — автоматическое изменение оформления ячейки при выполнении заданного условия.
  • Правило: если условие выполнено — меняется вид
  • Готовые наборы: больше, меньше, между, текст содержит
  • Цветовые шкалы и гистограммы показывают разброс
  • Правила имеют приоритет и могут перекрывать друг друга

Тезис: Условное форматирование: Условное форматирование

  • автоматическое изменение оформления ячейки при выполнении заданного условия.
  • Раскрашивать ячейки вручную — работа, которая устаревает при первом же изменении данных. Условное форматирование делает это автоматически: вы задаёте правило один раз, и…
  • Правило: если условие выполнено — меняется вид
  • Готовые наборы: больше, меньше, между, текст содержит

Подготовка листа к печати

Область печати — это диапазон, который программа выведет на бумагу. Без неё печатается всё, где есть данные, включая случайные пометки в дальних…

  • Область печати — диапазон, который попадёт на бумагу
  • Масштаб «вписать по ширине» спасает широкие таблицы
  • Строки заголовка повторяют на каждой странице
  • Перед печатью всегда смотрите предварительный просмотр

Проверка на понимание

В ячейке хранится число 0,256, установлен процентный формат с двумя знаками после запятой. Какое утверждение верно?

A
значение изменилось на 25,6 и участвует в формулах как 25,6
B
на экране видно 25,60%, а в формулах участвует 0,256
C
значение округлилось до 0,26 и сохранилось в таком виде
D
значение превратилось в текст «25,60%»

Выберите вариант — правильный подсветится зелёным.
